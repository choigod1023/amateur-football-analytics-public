# 사용자 지시와 환경의 함정

근거: `인수인계 문서(공개본에서 제외)` 2절과 10절 (2026-11-13), 이후 대화 (2026-11-16).

## 사용자 지시 (어기지 않을 것)
1. 한국어, 높임말(사용자님), 쉬운 단어. 엠대시를 쓰지 않습니다.
2. 푸시는 사용자님이 허락할 때만 합니다. 운영 서버 재시작과 워크트리 삭제도 먼저 묻습니다.
3. 보고서 영상에 데이터 한계 문구, 핵심 선수 상자, 미니맵, 선수 이동 경로, 공 표시를 넣지 않습니다. 원본 화질을 유지합니다.
4. 장면 설명은 구체적으로 씁니다(구역, 수비수, 빈 길). "중앙에서 시작한 공격" 같은 일반론이나 근거 없는 조언은 쓰지 않습니다.
5. 열린 패스길은 패스선에서 3m 안에 상대가 없는 길입니다. 막은 수비수를 표시합니다.
6. 훈련 내용은 보고서 한 장에 모읍니다. 정보는 많을수록 좋습니다.
7. 틀릴 수 있는 값을 사람의 답과 섞지 않습니다.
8. 외부 서비스로 사용자 개인 정보와 선수 이름을 보내지 않습니다.
9. 번호로 선수를 배정하기 전에 평균 위치가 명단의 포지션과 맞는지 확인합니다 (두 자리 등번호 둘을 혼동해서 후반 조각 7개를 잘못 배정한 적이 있음).
10. 사용자님이 직접 판정하는 부담을 줄이는 방향으로 일합니다(예: 모델이 훈련하거나 대신 판정할 수 있는 부분은 사람에게 묻지 않습니다).

## 서버 운영 요령
- 재시작: `scripts/run_review_server.ps1 -ConfigFile ../../work/report-config/server.json` (먼저 저장소를 백업). 상태는 `-Status`.
- 백그라운드로 돌리면 "실패, 종료 코드 1"로 보고되는데 서버는 정상 시작되는 일이 많습니다. `-Status`와 HTTP 200으로 확인합니다.
- 정적 파일(`web/*.html`, `*.js`)은 디스크에서 읽어 바로 반영되고 파이썬 경로는 재시작이 필요합니다.
- 평가와 이름 달기 화면은 인증이 없는 시제품 상태입니다. 공개 배포 전에는 인증을 추가해야 합니다.

## 환경의 함정
- OpenCV는 한글이 든 경로에 쓰지 못합니다. 출력 경로는 영문으로.
- H.264는 가로세로가 짝수여야 합니다.
- bash 안의 한글 here-document나 삼중 따옴표가 깨질 수 있습니다. 긴 스크립트는 파일로 저장해 실행합니다.
- PowerShell 5.1은 UTF-8 JSON을 콘솔에서 깨져 보이게 합니다(파일은 정상).
- 파일 크기가 30MB를 넘으면 휴대폰과 웹으로 전달되지 않습니다.
- JSON에 numpy 값을 넣으면 직렬화가 안 됩니다.
- 이 컴퓨터는 RTX 5070 12GB입니다. 학습 중에는 GPU를 다른 작업과 나눠 쓰지 않습니다.
