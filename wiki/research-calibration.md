# 연구 요약: 경기장 보정 (2026-11-10 ~ 11-11 연구)

근거: `docs/` 아래 calibration-research, calibration-builder, prepare-calibration-config, penalty-lines, field-error-audit, auto-field-research, partial-field-research, field-line-resume-1111, soccertrack-landmark-evaluation, green-temporal-recheck.
이 연구의 결과는 **자동 보정이 쓸 만하지 않다**는 것입니다. 현재 경기의 보정은 사람이 기준점을 찍어 만든 값(`calibrations.json`)을 씁니다.

## 현재 사용하는 방식
- 사람이 같은 프레임에서 경기장의 알려진 점(골라인, 페널티 구역 선 교차점 등)을 찍고, 미터 좌표와 대응시켜 호모그래피를 만듭니다 (`scripts/build_calibration.py`, `scripts/capture_calibration_frame.py`, `scripts/prepare_calibration_config.py`).
- 후보는 항상 `validated: false`로 나오고, 사용자가 독립 확인점으로 오차를 확인해 허용 기준을 정한 뒤에만 활성화합니다. 확인점이 3개 미만이거나 영역 밖이면 설정 파일을 만들지 않습니다.
- 페널티 지역 네 선의 교차로 보정을 만드는 도구(`scripts/calibrate_penalty_lines.py`)도 있습니다. AI Hub 정지 이미지에서 보정에 쓰지 않은 선의 교차점을 검사하면 985장 1,970점의 중앙 오차 0.161m, 90백분위 0.305m였습니다(105x68m 가정, 한 이미지 안의 다른 선끼리 비교한 값이라 실제 정확도가 아님).
- 보정은 카메라가 고정이라는 가정에 의존합니다. 카메라 이동 감시(ORB 특징점과 RANSAC, 변위 90백분위가 영상 너비의 0.3%를 넘으면 보류)가 있지만 임계값은 현장 데이터로 최적화한 값이 아닙니다.
- 이 경기는 카메라가 바뀝니다(cam1, cam2, cam3). cam2 구간은 보정이 없어서 카메라가 바뀐 구간의 골 2개가 분석에서 빠집니다.

## 자동 보정 실험 결과 (모두 채택하지 않음)
| 실험 | 결과 |
|---|---|
| 선 픽셀 분할 (작은 CNN, 8종 선) | 픽셀 정밀도 15.7%, 재현율 32.3% |
| 위 모델을 500프레임 추가 학습 | 정밀도 13.5%, 재현율 35.2% (교환일 뿐 개선 아님) |
| 직접 좌표 회귀 (166장) | 코너 오차 중앙값 136.5~143.7px, p90 353.6~363.3px (평균 좌표만 쓰면 401.8px) |
| 페널티 구역 교차점 회귀 (ResNet-18, 951장) | 네 점 평균 오차 중앙값 77.8~90.8px, p90 159.6~168.4px (1920x1080 기준) |
| 위 모델의 기준점 오류 분석 | 200프레임 중 79프레임이 100px 초과, 기준점 하나에 큰 오차가 몰림 |
| 밝은 픽셀로 후보 거르기 / 코너로 이동 | 개선 없음(개선 21프레임, 악화 30프레임) |
| 녹색 경기장 후보를 시간 방향으로 합치기 | 체크포인트 오차 중앙값 15~18m. 전술 위치에 쓸 수 없음 |
| SoccerTrack 제공 기준점 | 61점 중 일부만 변환, 중앙 0.48~0.69m, p90 1.3m (그 영상 전용) |

공통 한계: 한 경기의 인접 프레임이 서로 상관되어 있고, 같은 경기를 개발에 반복 사용했으며, 미터 단위 위치 오차가 아니라 픽셀 거리입니다. 자동 승인은 금지되어 있습니다.

## 교훈
- 이 프로젝트에서는 사람이 찍은 기준점이 훨씬 믿을 만합니다. 보정 오차는 팀 모양의 절대 길이와 폭에 그대로 들어가므로, 같은 칸끼리의 비교만 믿습니다 ([pipeline-and-paths.md](pipeline-and-paths.md)).
- cam2 보정을 사람이 만들면 빠진 골 2개를 분석에 넣을 수 있습니다 ([review-store-and-open-tasks.md](review-store-and-open-tasks.md)의 남은 일).
- 렌즈 왜곡은 보정에 반영하지 않습니다(평면 호모그래피). 선수 발이 평면에 있다는 근사를 씁니다.
