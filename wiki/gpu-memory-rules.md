## 규칙
| 항목 | 기준 |
|---|---|
| 동시 실행 | GPU 작업은 하나만. 여러 실험은 순서대로 |
| 시작 조건 | 그래픽 메모리 8 GB, 일반 메모리 12 GB 이상 비어 있을 때 |
| 작업 하나의 상한 | 그래픽 메모리 8 GB (`torch.cuda.set_per_process_memory_fraction`) |
| 자동 중지 | 일반 메모리 90% 또는 그래픽 메모리 95%를 두 번 연속 넘으면 |
| 우선순위 | 실험은 낮은 우선순위(라이브, 녹화, 서버가 먼저) |
| 경기 날 | 경기 2시간 전부터 끝날 때까지 GPU 실험 금지. 라이브가 돌면 감시 도구가 거부 |
| 새 실험 | 작은 표본으로 먼저 돌려 최대 메모리를 보고 전체 실행 |
| 자료 읽기 | 클립 전체를 한꺼번에 올리지 않음. 추론 배치 4~8, 가능하면 fp16. YOLO 학습은 `cache=False`, `workers=2`부터 |

평소에도 일반 메모리를 약 20 GB(65%) 쓰므로(브라우저, 서버, 녹화) 실험에 쓸 수 있는 여유는 약 10 GB입니다.
