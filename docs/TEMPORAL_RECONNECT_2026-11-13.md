# 여러 프레임·이동 방향을 학습한 선수 재연결

## 결과와 운영 결정

같은 유니폼의 선수를 구별하기 위해 직전 최대 5회 관측과 재등장 직후 3회 관측을 함께 비교하는 모델을 구현하고 학습했다. 사용자 경기와 다른 두 경기의 90초씩, 합계 180초·900프레임으로 평가했다.

이전 단일 프레임 학습 모델 대비 ID 변경은 3264→3263으로 1회(0.031%) 줄었다. 확인된 다른 선수 연결은 3→2건이지만, 연결 경계의 정답을 확정할 수 없는 건수는 3→8건으로 증가했다. **확실한 정확도 향상으로 판단하지 않으며 새 모델은 운영에 배포하지 않았다.** 서버와 녹화는 재시작하지 않았다. 탐지기 자체의 재학습이나 코칭 성능 향상을 주장하는 결과가 아니다.

## 변경 내용

- 여러 원본 크롭의 상·하의 색 분포를 평균하고 관측 간 외형 변동을 계산한다.
- 실제 관측 시간과 발끝 좌표의 쌍별 기울기 중앙값으로 이동 속도·방향을 계산한다.
- 사라지기 전 움직임으로 재등장 위치를 예측한 오차와, 재등장 뒤 움직임으로 이전 위치를 역산한 오차를 함께 학습한다. 이 계산은 연결 검사용이며 미니맵에 추정 위치를 추가하지 않는다.
- 14개 특징을 사용하는 정규화·정규화항 포함 로지스틱 분류기다. 딥러닝 ReID 임베딩이나 등번호 인식기를 새로 훈련한 것은 아니다.
- 재등장 3회 연속 관측에서만 판정한다. 5fps에서 처음 2프레임을 0.4초 동안 보류해 확인한 ID로 게시하며, 이미 게시한 과거 프레임은 고치지 않는다.
- 동시에 존재하는 선수, 겹치는 트랙 구간, 비슷한 점수의 경쟁 후보, 이동 예측 잔차가 큰 후보는 연결하지 않는다. 새 상자·가상 선수는 만들지 않는다.
- 동일 raw ID 안에서 인물이 이미 바뀐 문제는 별도 문제다. 이번 모델은 새로운 raw ID의 연결을 다룬다.

## 학습 자료

기존 장면 답변 6쌍을 검사해 실제 여러 관측을 사용할 수 있는 d0105·d0108·d0109·d0110 4쌍만 학습했다. 같은 선수 3쌍, 다른 선수 1쌍으로 매우 적다. 학습에 실제 사용한 원본 프레임은 앞쪽 19장과 뒤쪽 12장이다. 여러 프레임은 서로 상관된 자료이며 31개의 독립 정답으로 계산하지 않는다.

- d0106: 겹친 사람을 포함한 상자 높이가 57.9→43→31.4→26.8px로 변한다. 끝점의 답을 주변 전체 시퀀스의 동일인 정답으로 확장하기 어려워 제외했다.
- d0107: 앞쪽 1초에 실제 관측은 1개이고 나머지는 보간 상자여서 제외했다.
- d0110: 앞쪽 마지막 관측 사이에 0.6초 누락이 있다. 실제 시간 간격을 사용했고 중간 프레임·상자를 생성하지 않았다.
- 원본 크롭을 사용하고 노란 표시가 있는 검토용 이미지는 학습하지 않았다. 답변 해시, 현재 질문 fingerprint, 원본 프레임 해시를 확인했다.
- 짧은 트랙 내부 동일성은 원본을 검토한 가정이다. 모든 중간 프레임을 사람이 별도로 정답 판정한 것은 아니다.
- 모든 사용자 경기 클립은 `own-match-20261111` 하나로 묶었다. 사용자 답변이나 ID 자체를 입력 특징으로 사용하지 않았다.

이전 모델은 6쌍, 이번 모델은 정제한 4쌍을 사용하므로 결과는 전체 후보 시스템 비교다. 여러 프레임 특징만의 효과를 분리한 실험으로 해석하지 않는다.

## 사전에 고정한 평가

`work/temporal-reconnect-20261113/frozen-evaluation-plan.json`에 모델 해시와 평가 계획을 저장한 후 추론했다. 점수 0.90, 경쟁 후보 차이 0.15, 양방향 위치 예측 오차 최대 1.5명 키, 최대 연결 공백 2.5초를 고정했다. 평가 결과로 임계값을 조정하지 않았다.

| 경기 그룹 | 영상 | 정답 |
|---|---|---|
| aihub-match-305 | work/aihub-coaching-eval/video-02.mp4 | work/aihub-role-study/final-305-track.json |

YOLO11n imgsz=1280, conf=0.1, ByteTrack 설정을 이전 실험과 동일하게 사용했다. 세 방법 모두 같은 탐지 상자와 같은 450프레임/경기를 채점한다. 일부 탐지를 인위적으로 삭제하지 않았고 정답은 추론·연결·임계값 선택에 사용하지 않았다.

ByteTrack 기준 감소도 8회(0.245%)에 그친다. 높은 수치는 실제 선수 수가 아니라 반복된 관측의 ID 전환 횟수다. 5fps로 건너뛰는 사이 작은 상자가 카메라 이동 등의 영향으로 겹치지 않아 기본 추적부터 심하게 분열하는 조건이다. 운영 전체 정확도를 뜻하지 않는다.

### 연결 경계 전체의 추가 감사

기존 채점은 연결 결정 시점의 정답 한 개와 이전 트랙의 마지막 매칭 성공 정답만 비교했다. 이 방식은 앞선 2개 확인 프레임의 잘못된 연결이나 마지막 관측의 정답 누락을 놓칠 수 있다. 별도 감사 코드로 **이전 트랙의 실제 마지막 관측과 새 트랙의 출생부터 결정까지 모든 관측**을 검사했다. 오래된 정답을 대신 쓰지 않고, 누락된 정답은 판정 불가로 남겼다. 모델·임계값·추론 결과는 바꾸지 않았다.

| 경계 감사 | 단일 프레임 학습 | 여러 프레임 학습 |
|---|---:|---:|
| 연결 시도 | 16 | 15 |
| 정답 확인 | 10 | 5 |
| 다른 선수 연결 확인 | 3 | 2 |
| 정답 대응 부족으로 판정 불가 | 3 | 8 |

오연결이 1건 줄었다고 전체 연결 정확도가 향상됐다고 단정할 수 없다. 후보 수와 확인 가능 범위가 다르고 표본도 작다. 기존 방식대로 결정 순간만 보면 새 모델 정답 8건·오연결 2건·미확인 5건이지만, 최종 결론은 위의 더 엄격한 감사를 따른다.

세 방법의 정답 대응 관측 5878개, 미탐 정답 관측 12234개, 정답 미대응 탐지 5287개는 동일하다. 새 모델은 탐지 상자를 추가하지 않으므로 탐지 오탐·미탐 감소를 입증하지 못했다. 미대응 탐지에는 정답에 없는 관중 등이 포함될 수 있어 전부 오탐이라고 할 수 없다. 채점은 IoU≥0.5 탐욕 대응 진단이며 공식 HOTA·IDF1이 아니다.

## 필요한 사람 확인

이미 게시한 d0111(359→845), d0112(10→779)가 아직 미응답이다. 같은 유니폼·불확실한 움직임을 판별할 자료가 필요하므로 두 장면을 유지했다. 중복 질문은 추가하지 않았다.

http://<SERVER_HOST>:8443/train/reappearance

앞뒤 영상·전체 화면과 확대 화면·끝점 사진을 제공한다. 페이지와 두 영상·네 사진 HTTP 200, 대기 2건을 확인했다. 서버 PC에서 공인 주소로 확인했으며 별도 셀룰러 단말 시험은 아니다. 기존 JSON 1190개의 해시가 모두 동일하다. 답변 저장 후에도 자동 운영 배포를 뜻하지 않는다.

## 다음에 개선할 부분

1. 기존 두 질문의 답을 반영해 같은 유니폼의 다른 선수 사례를 보강한다. 현재 음성 예가 한 쌍이므로 안정적인 개인 재식별을 학습하기에 부족하다.
2. 분석·코칭 출력 주기와 추적 업데이트 주기를 분리하고 카메라 이동 보정을 평가한다. 먼저 원시 ID가 계속 끊기는 문제를 줄여야 한다.
3. 여러 시점의 외형 임베딩과 이동을 결합한 모델, raw ID 내부 교체 검출을 별도로 비교한다. 카메라 이동과 선수 이동을 분리하지 않은 화면 좌표 속도에는 한계가 있다.
4. 이번 두 경기를 보고 모델을 조정한 다음에는 별도 최종 평가 경기로 재검증한다. 본 결과를 반복 튜닝 후 독립 평가로 재사용하지 않는다.

## 재현과 구현 검증

프로젝트 가상환경에서 실행한다. 출력 경로는 새 경로여야 한다.

```powershell
python scripts/train_temporal_reconnect.py TRAIN_SEQUENCES MODEL
python scripts/evaluate_temporal_reconnect.py VIDEO TRACK_JSON MODEL PREVIOUS_MODEL YOLO_WEIGHTS OUTPUT --group MATCH_GROUP
python -m pytest -q
```

학습 manifest의 pairs에는 id, label, video_group, answer_path, answer_sha256, before/after 관측 목록이 필요하다. 각 관측은 frame_path, frame_sha256, box_xyxy, time을 포함한다. 실제 경기 단위 group을 부여해야 하며 평가기는 학습 group 재사용을 거부한다.

`work/temporal-reconnect-20261113/`에 train-sequences.json, model.json, 평가 계획, eval-305/306의 comparison/events/trace와 boundary-audit/boundary-summary, 원본 해시, 페이지 확인을 저장했다. 학습 자료 추출은 같은 폴더의 prepare_sequences.py로 수행했다. 모델·프레임·영상·사용자 답은 Git에 넣지 않는다.

전체 테스트 479개 통과·1개 건너뜀. 이후 추가한 경계 채점 회귀 테스트 3개와 시계열 테스트 6개를 다시 실행해 9개 모두 통과했다. 미래 정보 없이 3회 확인, 상자 비생성, 비연속 재등장 보류, 겹침·경쟁 후보 보류, 같은 유니폼의 반대 이동 특징, 오래된 정답 재사용 금지 등을 검사했다.
