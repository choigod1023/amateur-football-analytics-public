# 고정 카메라 보정 후보를 서버 설정에 연결

1. 고정한 카메라의 영상에서 `scripts/capture_calibration_frame.py`로 원본 해상도 프레임을 저장한다. 별도로 실제 경기장 길이와 폭을 재고, 같은 프레임에서 서로 대응하는 네 곳 이상의 픽셀·미터 좌표를 `docs/calibration-builder.md`의 `fitting_points` 형식으로 기록한다. 다른 위치의 독립 확인점은 `checkpoints`에 기록한다. 공격 방향, 경기장 좌표 원점과 홈/원정은 자동으로 결정되지 않는다.
2. 서버의 기존 설정을 보존한 채 보정 후보를 새 파일에 준비한다. 아래 경로는 형식 예시이며 파일은 실제 사용자가 만든 값을 지정한다.

```powershell
.venv\Scripts\python.exe scripts\prepare_calibration_config.py --base config.json --measurements measurements.json --reference calibration-frame.png --output config-candidate.json
```

후보의 `validated`는 항상 false여서 좌표가 나오지 않는다. 출력의 검증점 오류와 보류 사유를 확인한다. 명시적으로 서로 다른 검증점 3개 이상이 모두 사각형 안에서 측정돼야 하며 현장 측정·선 식별 오차, 구장 크기와 고정 구도를 검토한다. 가드의 특징점이 부족하면 보정 자체가 보류될 수 있다.

3. 사용자가 독립 측정값과 기준 프레임을 직접 확인하고 고정 카메라임을 확인한 경우에만 용도에 맞는 허용 오차를 직접 정해 활성 설정을 새 파일로 작성한다. 예시 `0.5`는 **허용 기준을 정하라는 형식 예시이지 정확도 보증이나 권장치가 아니다**.

```powershell
.venv\Scripts\python.exe scripts\prepare_calibration_config.py --base config.json --measurements measurements.json --reference calibration-frame.png --max-error-m 0.5 --accept-measured --output config-verified.json
```

기존 파일은 덮어쓰지 않는다. 확인점이 셋 미만이거나 일부가 영역 밖이거나 사용자가 정한 최대 오차를 넘으면 설정 파일을 생성하지 않는다. 이 검사는 **현장 측정의 진실성, 고정 카메라 상태 또는 선수 발 위치를 증명하지 않는다**. 선을 사용한 추정점은 실측값이 아니며 오차의 기준으로 쓰려면 그 한계를 적어야 한다. 기준 프레임 경로가 camera guard로 연결되고, 참조 영상이 없거나 특징점이 부족하거나 이동하면 위치는 출력되지 않는다. 카메라 가드는 모든 움직임을 잡지 못한다.

필요하면 `measurements.json`에 원본 픽셀 좌표의 `camera_guard_feature_region`(순서가 맞는 볼록 사각형 네 점)을 넣어 보정 폴리곤과 다른 **움직이지 않는 배경**을 검사할 수 있다. 이 영역은 움직임을 감지할 특징점 추출에만 쓰이며 위치 출력 영역은 여전히 원래 보정 사각형이다. 사람·움직이는 광고판을 피해야 한다. 참조 프레임의 경기와 카메라가 실제 입력과 같음을 확인해야 한다.

팀 분류와 역할 검증 여부는 이 도구가 바꾸지 않는다. 팀 표본·선수/심판 구분이 불확실하면 코칭을 검증된 결과로 취급할 수 없다. 서버를 바꾸거나 시작하지 않으며, 파일은 모두 새 경로에만 작성한다.

## 공개 고정 카메라 연구 연결 시험

ISSIA 고정 카메라 5 공개 영상의 선 교차점 픽셀을 화면에서 근사하여 4개 피팅점으로 사용했고, [공개 ISSIA-3D 카메라 모델](https://github.com/mguti97/SoccerNet-v3D)의 추정 투영에서 도출한 다른 3점을 확인점으로 삼았다. `105×68m`를 가정했을 때 최대 차이는 0.433m, 중앙 0.330m였고, 별도로 지정한 영상 배경 영역의 가드는 연속 50프레임 모두 `stable`을 반환했다. 이 실험에서만 1m 기준으로 명시적 활성화를 가정했다.

표시점은 시각적으로 근사했고 검증점은 카메라 모델로 추정했으므로 **독립 실측이 아니다**. 105×68m는 모델 시험용 가정이며 실제 ISSIA 경기장의 검증된 실측 크기로 주장하지 않는다. 50프레임은 약 2초의 한 영상일 뿐 장시간 안정성이나 팀 구분·선수 위치 정확도는 검증하지 않는다. 영상·주석과 연구자 모델 각각의 이용 조건을 별도로 확인해야 하며 테스트 결과를 실전으로 일반화하지 않는다.
