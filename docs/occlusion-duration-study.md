# 화면에서 사라진 선수 위치의 시간별 오차 실험

현재 광각 경기의 60~90초와 120~150초의 공개 주석 궤적을 사용했다. 정답 ID와 마지막 두 주석 발점이 알려져 있다고 가정하고 0.2초 간격의 등속 운동을 추정해 미래 주석 발점과 비교했다. 저자가 제공한 경기장 기준점과 105×68m 좌표계로 투영한 상대 오차이며, 실측 선수 위치와의 오차가 아니다. 같은 경기의 상관된 관측이고 실제 탐지 손실, ID 교체, 화면 밖 재식별, 카메라·네트워크 지연은 반영하지 않는다. 이 조건은 실제 사용보다 유리하다.

| 가림 시간 | 예상 오차 중앙값 | 예상 오차 p90 | 마지막 위치 고정 p90 | 예상 가능한 표본 |
|---|---:|---:|---:|---:|
| 0.8초 | 0.31m | 1.65m | 3.66m | 2,632/2,644 |
| 2초 | 1.74m | 5.51m | 8.79m | 2,592/2,626 |
| 3초 | 3.35m | 9.16m | 12.80m | 2,522/2,615 |
| 5초 | 6.61m | 16.95m | 20.20m | 2,355/2,603 |

이 실험은 5초 예측을 제품에서 켜라는 근거가 아니다. 후보 속도 제한이나 영역 제약을 통과하지 못한 사례는 오차 집계에서 빠진다. 이전 실제 탐지 노이즈가 포함된 68건의 가림 실험에서는 0.8초 추정의 p90이 고정 표시보다 컸다. 따라서 실제 추적 오차와 ID 재결합, 카메라 오차를 측정하고 불확실성을 표시하기 전까지 기존 런타임의 0.8초 제한을 바꾸지 않는다.

로컬 접근이 가능한 원자료와 실험 보정 파일이 있을 때 재현: `python scripts/evaluate_occlusion_candidates.py --calibration <후보.json> --horizons 20 50 75 125 --max-age 5.01 -- <주석1.csv> <주석2.csv>`. 기본 실행의 최대 추정 시간은 기존처럼 0.8초다.
