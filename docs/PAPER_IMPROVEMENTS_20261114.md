# 논문 기반 분류·재연결·위치 개선 실험

2026-11-14. 운영 모델, 운영 서버, 녹화 설정은 변경하지 않는다. 각 실험은 실제 결과가 좋아지는지를 확인하기 위한 후보이며, 구현 자체를 정확도 향상으로 간주하지 않는다.

## 분류 답이 많아도 같은 선수를 구분하지 못하는 이유

팀/역할 답과 선수 신원 답은 서로 다른 학습 목표다. 같은 팀이라는 답만으로 두 사람이 같은 선수인지 배울 수 없다. 기존 분류기는 색상과 상자 통계 24개를 받으므로 유니폼 무늬나 신체 부분의 배열을 직접 비교하지 못한다. 반대로 재연결 학습에 사용한 사람 확인 쌍은 4개뿐이다. 팀 답 수백 개를 신원 학습 수백 쌍으로 환산해서는 안 된다.

[BPBreID](https://arxiv.org/abs/2211.03679)는 신체 부분 표현과 가림 대응을 연구한다. 이번에는 공간 신체 특징과 대상 인물을 제거한 주변 맥락을 각각 추가하는 대조 실험을 구현했다. 논문 전체 모델을 재현한 것은 아니다. [분류 실험 기록](VISUAL_CONTEXT_EXPERIMENT_20261114.md)에 입력, 분할, 결과와 한계를 남겼다.

기존 740개 학습 답 / 고정 평가 136개에서 색상 기준은 126/136, 공간 신체 추가는 123/136, 신체+맥락은 125/136이었다. 새 관중 사례를 맞혔지만 평가 심판 재현율은 악화됐다. 확대와 특징 추가만으로 해결된다는 가설은 이 실험에서 지지되지 않았다. 평가 자료는 같은 경기의 4장/2개 시간대이며 독립 경기 검증이 아니다.

후속으로 공식 ImageNet 사전학습 MobileNetV3-small을 동결해 576개 특징과 기존 24개 특징을 결합했다. 이 후보 역시 123/136으로 기준보다 나빴다. 공간/CNN 후보는 학습 740개와 새 답 5개를 모두 맞혔지만 일반화가 개선되지 않았다. 같은 평가 세트를 반복 확인했으므로 이 세트는 개발 비교용이며, 향후 최종 성능은 새 경기나 구도로 검증해야 한다. 가중치는 프로젝트 캐시에만 내려받았고 운영에는 연결하지 않았다.

## 여러 재연결 후보를 함께 비교

[비용 흐름 기반 추적 연구](https://www.cvlibs.net/projects/autonomous_vision_survey/literature/Zhang2008CVPR.pdf)의 배타적 연결 원리를 참고해, 제한된 후보 창에서 전체 할당을 비교하는 모듈을 구현했다. 기존의 앞 5장·뒤 3장 관측 및 운동 잔차는 유지한다. 같은 선수를 두 사람에게 연결하지 않고, 미연결을 정식 선택지로 둔다. 최선의 연결을 제외한 대안과 차이가 작으면 승인하지 않는다.

[OC-SORT](https://arxiv.org/abs/2203.14360)가 다루는 가림 후 운동 오차도 중요하지만, 이번 코드를 OC-SORT 재현이라고 부르지 않는다. 현재 실험은 재연결 할당 변경을 분리해 검증한다. [재연결 실험 기록](GLOBAL_RECONNECT_RESEARCH_2026-11-14.md)에 실제 영상 평가와 후보 감사 결과를 기록한다.

AI Hub 별도 경기 305·306에서 총 180초/900분석 프레임을 실제 디코딩·탐지하여 다시 비교했다. 기존/새 방식 모두 ID 변경 3,263회, 연결 시점 판정상 오연결 2회였다. 더 엄격한 앞뒤 경계 감사도 정연결 5·오연결 2·미확정 8로 동일했다. 이 실험에서는 할당 방식 변경의 개선을 확인하지 못했다. ID 변경 수는 기존 IoU 진단 채점이며 공식 HOTA/IDF1은 아니다.

저장된 후보는 66개, 경쟁 후보가 있는 창은 8개뿐이었다. 모든 단절이 후보 비교 단계까지 도달하는 것은 아니다. 따라서 다음 우선순위는 경쟁 최적화의 추가 복잡화보다 후보 생성 전 미탐·단절과 운동 잔차 탈락을 분리하고, 같은 사람/다른 사람 쌍의 판별력을 검증하는 것이다. 이것은 이번 결과에 따른 개발 우선순위이며, 모든 단절의 원인을 확정한 결론은 아니다.

## 위치를 부드럽게 표시하는 것과 올바른 위치의 차이

새 위치 품질 모듈은 발점 주변의 픽셀 변화가 경기장 좌표에서 얼마나 증폭되는지 계산한다. 선 밖 좌표를 안으로 밀어 넣지 않으며, 경계 불확실성과 투영 실패를 구분한다. ±3픽셀은 측정된 잡음 분포가 아닌 명시적인 시험 조건이다.

60초/300프레임의 기존 팀별 위치 후보 5,358개를 원시 상자와 연결했다. 이 조건의 위치 변화 반경 중앙값은 1.728m, 95백분위는 3.125m였다. 중심이 경기장 밖인 후보는 39개, 경계가 불확실한 후보는 58개였다. 이는 실제 선수 위치 오차나 오탐 개수가 아니다. 팀 분류 오류도 포함될 수 있는 운영 후보 집합의 진단이다.

보정의 사용 기준점 오차 RMS는 0.961m지만, 기준점을 하나씩 빼고 검증하면 최대 4.115m였다. 실제 경기장 치수도 추정치이므로 이 값을 위치 정확도로 쓰면 안 된다. [PnLCalib](https://arxiv.org/abs/2404.08401)·[TVCalib](https://arxiv.org/abs/2207.11709)의 점과 선을 함께 이용하는 보정이 다음 비교 대상이다. 이번 구현은 그 보정 모델을 새로 학습한 것이 아니다. [위치 실험 기록](POSITION_QUALITY_EXPERIMENT_20261114.md)에 계산 및 재현 명령을 남겼다.

## 코칭에 적용할 조건

현재 실험은 코칭 정답률 향상을 입증하지 않는다. 위치 흔들림을 시각적으로 숨기거나, 팀별 11명을 강제로 채워 코칭의 근거로 쓰지 않는다. 작은 거리 차이에 의존하는 고립·침투 판단은 보정과 발점 변화에도 결론이 유지되는지 별도로 검증해야 한다. 임의의 ±3픽셀 조건을 곧바로 운영 차단 임계값으로 적용하면 정상 관측까지 대량 누락될 수 있다.

[SoccerNet-GSR](https://arxiv.org/abs/2404.11335)처럼 역할·팀·신원·위치를 나눠 평가해야 한다. 팀 분류가 좋아져도 신원 연결이나 미터 단위 위치가 좋아졌다고 단정할 수 없다.

다음 사람 확인은 이미 답한 팀을 다시 묻는 대신, 모델 간 의견이 갈리는 짧은 전후 궤적의 동일인 여부와 원거리 선수의 실제 발점에 한정한다. 현재 실험에서 선별·게시하지 않은 장면을 훈련 페이지에 올라갔다고 보고하지 않는다.
