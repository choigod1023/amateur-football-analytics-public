# 한시적 파일 수신기

`app.transfer_once`는 독립된 HTTP 서비스이며 기존 대시보드/API를 제공하지 않습니다. 운영자가 정한 기존 전용 디렉터리와 단일 파일명만 허용하고 `POST /upload` 한 건을 받은 뒤 종료합니다. 수신 성공이 없더라도 시작 후 30분에 종료를 요청합니다. 외부에서 파일명이나 저장 경로를 지정할 수 없고, 파일명 유효성 검사를 통과해야 하며 이미 대상이 있으면 덮어쓰지 않습니다. 단일 출발지 IPv4를 소켓 주소로 검사하고 전달 헤더는 신뢰하지 않습니다. 수신 크기 상한은 8GiB, 본문 `Content-Length` 및 `X-Content-SHA256` 검사에 성공한 뒤에만 파일이 확정됩니다. 이 서비스는 사용자가 선택한 평문 HTTP이며 인증·암호화를 제공하지 않습니다. IP 제한은 사용자 인증이나 도청 방지가 아닙니다.

로컬 구성: 전용 빈 폴더를 미리 만들고 `TRANSFER_DIR`(절대 경로), `TRANSFER_FILENAME`(예: `mac-migration.zip`), `TRANSFER_SOURCE_IP`(단일 송출지), `TRANSFER_BIND_IP`(수신 인터페이스, 기본 loopback)를 별도 지정합니다. `.venv\Scripts\python.exe -m app.transfer_once`로 실행합니다. 기존 8443 서비스가 점유 중이면 먼저 사용자 요청에 맞춰 해당 서비스를 중지한 뒤 사용해야 하며, 1회 전송이 끝나면 원래 서비스를 복구해야 합니다. 이 문서는 실행·포워딩·방화벽 변경을 수행하지 않습니다.

송신자는 파일 SHA-256 해시를 계산한 다음 `Content-Type: application/octet-stream`, `X-Content-SHA256: <64자리 해시>`와 정확한 `Content-Length`를 가진 요청으로 `POST /upload`에 파일을 전송합니다. 200 응답의 바이트 수와 SHA-256을 송신 파일과 대조합니다. 실패하거나 연결이 끊어지면 미완성 파일은 자동 정리하며 최종 이름은 생성되지 않습니다. 프로세스 강제 종료 시 임시 `.part` 파일이 남을 수 있어 따로 점검해야 합니다. 테스트를 위해 전송된 ZIP은 신뢰된 것으로 가정하지 말고 경로 검증과 해시 확인 후 별도 위치에 압축을 푸세요.
