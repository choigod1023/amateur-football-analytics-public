# 선수 포지션 추론 가능성 확인

## 연구 근거와 구현 범위

[SoccerCPD](https://arxiv.org/abs/2206.10926)는 선수 궤적에서 프레임별 역할을 배정한 뒤, 순간적 위치 이동과 지속적인 역할·대형 변화를 구분하는 방법을 제안한다. 이 실험은 논문의 학습 모델이나 알고리즘을 재현한 것이 아니다. 공인된 포지션 모델을 확보했다고 주장하지 않는다.

현재 보유한 SoccerTrack 경기의 CSV에는 팀·임시 선수 ID·영상상 선수 상자가 있으나 개별 선수의 수비수·미드필더·공격수나 골키퍼 역할 정답은 확인되지 않았다. 따라서 포지션 분류 정확도는 평가할 수 없다. 제공자의 네 기준점으로 만든 해당 영상 전용 보정도 선수 위치 정확도와 실제 경기장의 크기를 별도 검증하지 않았다. 팀과 ID를 주석에서 사용한 결과이므로 실시간 자동 추론 결과가 아니다.

## 실제 영상 주석을 사용한 제한된 실험

`scripts/experimental_position_bands.py`는 각 팀에서 관측 ID가 최소 6개이고 개별 ID에 대해 20초 이상·15회 이상의 발 위치가 있을 때, 한 구간의 중앙 x 위치를 팀 내에서 3개 순위 구간으로 나눈다. 공격 방향은 외부에서 명시된 것으로 가정한다. 동률 경계는 보류하며, 이는 후방·중앙·전방의 **상대 위치 밴드**일 뿐 선수의 등록 포지션이나 전술 역할이 아니다. 실험에서 공격 방향은 양 팀 모두 같은 방향이라는 임의 가정을 사용했다. 방향 변경의 효과를 보여주는 실험이며 실제 해당 경기의 공격 방향을 주장하지 않는다. 골키퍼·심판도 자동으로 제거되지 않아 특정 전술 포지션 이름을 부여하지 않는다.

네 개의 30초 구간을 1초 간격으로 표본화하고 각 구간의 정답 상자 밑면 중앙을 저자 제공 기준점 변환으로 투영했다. 0~30초와 30~60초를 비교하면 같은 선수의 공간 밴드가 팀 0에서 10명 중 5명, 팀 1에서 11명 중 2명이 달라졌다. 다음 인접 구간에서는 각각 11명 중 4명과 11명 중 2명이 달라졌다. 60~90초와 120~150초 사이에는 중간 30초가 없으므로 연속 구간 비교가 아니다. 변화는 실제 움직임·추정 흔들림·시간창의 영향을 모두 포함하며 오분류율이나 역할 변경의 정답이 아니다.

공격 방향 가정을 반전시키면 첫 30초 구간에서 같은 10명 중 8명, 다른 팀 11명 중 8명의 공간 밴드가 달라진다. 경기 방향을 모르면 위치만 보고 후방·전방이나 DF/MF/FW를 결정할 수 없음을 보여주는 진단이다.

정확한 포지션 후보를 실시간에 연결하려면 우선 1) 필드 선수·골키퍼 및 팀을 분리하고 2) ID 전환을 줄여 충분한 기간의 궤적을 확보하고 3) 팀별 공격 방향 및 전후반 전환을 확인하고 4) 경기 단위로 분리한 역할 정답을 마련해야 한다. 이상을 검증하기 전 이 실험 결과는 대시보드, 실시간 API, 코칭에 사용하지 않는다.

접근이 승인된 로컬 자료를 보유한 환경에서 재현:

```powershell
python scripts/experimental_position_bands.py <경기-CSV-폴더> <candidate-unvalidated.json>
python -m pytest -q tests/test_position_bands.py
```
