# 고립·침투 누락과 추적 근거 재검증

기준 버전은 6dc59a7이다. 기존 답은 개발 검증 자료로 사용했으며 새 경기 독립 성능으로 해석하지 않는다.

## 고립: 원인을 수정하고 실제 관측으로 복구

1973초 마지막 표본은 B팀 5명으로 최소 인원 조건을 못 채웠지만, 그 초 앞 3개 실제 프레임에는 6~7명과 약 17m 고립이 있었다. 1975초 마지막 표본도 앞선 선수 선택이 바뀌어 9.4m가 됐지만 앞 3개 실제 표본은 16.7~17.7m였다. 초당 마지막 프레임만 사용하는 방식 때문에 6초 연속 조건이 끊겼다.

초당 최소 60%의 실제 유효 표본(5fps에서 3개)이 있을 때 고립 측정값의 중앙값을 사용한다. 위치를 보간하거나 잃어버린 선수를 만들어 넣지 않는다. 고립은 앞선 선수 배치의 지속성으로 계산하며, 같은 개인이 6초 내내 고립됐다는 신원 연속성은 보증하지 않는다. 초별 관측 수와 leader ID 목록을 결과 evidence에 포함한다.

1976초 정보성 수비선 관측 변동이 행동 지시용 8초 대기 시간을 점유하던 문제도 수정했다. 정보성 관측 자체의 중복 방지 시간은 유지한다.

결과: **1977초(32:57) 고립 복구, 1980초 박스 공격 인원 알림 유지**. 후반 전체 알림은 41→44개다. 추가된 세 알림이 모두 정확하다는 뜻은 아니다. 기존 6개 검토 구간 중 나머지 다섯 구간의 알림 종류는 유지됐다.

## 침투: 복구하지 않은 이유를 원시 자료로 확인

후보 ID5869의 2086~2090초 21프레임 중 실제 관측 13개, 보간 7개, 완전 누락 1개다. 변경하지 않은 80% 조건에는 실제 관측 17개가 필요하다. 보간 7개는 2088.6~2089.8초다.

해당 7프레임의 보간 상자 중심 반 키 이내에서 confidence 0.1 이상 원시 검출은 0/7이었다. 영상 표본에서는 어두운 유니폼 선수가 왼쪽에 남아 움직이는데 보간 경로는 오른쪽의 다른 형광 조끼 선수 쪽으로 이어지는 정황이 있다. 따라서 단순 탐지 누락뿐 아니라 조각 내부 ID 전환과 그 사이 잘못된 보간을 의심해야 한다.

이는 해당 경로의 근거가 불충분하다는 판단이지 경기에서 어떤 선수도 침투하지 않았다는 판정이 아니다. 사용자의 이전 설명 선호도 삭제하지 않았다. 원래 알림을 복구하기 위해 관측 비율·속도·시간 조건을 완화하지 않았다. 보간 7개로 가짜 침투가 완성되지 않도록 관측 필터와 침투 계산을 함께 검사하는 회귀 시험을 추가했다.

## 추적: 답과 불일치를 실제 오연결로 단정하지 않음

기존 답과 비교한 연결 일치는 same 3/14, different 불일치 1/25로 유지된다. 마지막 불일치5574→6182의 경계 영상363.6→363.8초는 거의 같은 위치에서 형광 조끼 인물이 이어진다. 전체 조각 내부의 대상 변화와 답의 시점 범위를 확인해야 한다. 경계 연결 자체가 틀렸다고 확정하거나 숫자를 맞추기 위해 막지 않았다.

평가 코드도 수정했다. 연결 시 원본 조각→출력 조각 membership을 기록해 겹침 제거로 행이 모두 사라진 원본도 평가에서 빠지지 않는다. 이번 자료에는 완전히 소비된 조각이 없어 수치 변화는 없다. 세 기존 평가 스크립트도 이 mapping을 사용한다. 원본 영상·검출·분류 답을 변경하지 않았다.

## 검증 및 운영

Python 전체 테스트 408개 통과, 1개 건너뜀. JavaScript 구문 검사 통과. 평가·화면 변경은 원본 답을 쓰지 않는 방식으로 구현했다. 고립 누락을 전제로 만든 미응답 비교 d0104는 이전 버전 기록으로 보관하며 새 질문으로 반복하지 않는다. 기록과 기존 답은 삭제하지 않는다. d0101의 별도 문구 확인은 유지한다.

검토 서버만 백업 후 갱신한다. SRT 녹화와 기존 트랙/모델 가중치는 교체하지 않는다. 자동 개별 선수 재식별, 전체 HOTA/IDF1 향상, 새로운 경기에서의 코칭 정확도는 입증되지 않았다.
