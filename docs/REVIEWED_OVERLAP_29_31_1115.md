# ID29/31 사용자 확인 반영

사용자 답: **서로 다른 선수**.

녹화 구간 11.6~13.0초(원본 오프셋1950초)의 두 상자는 같은 선수의 상·하체 중복이 아니라 서로 다른 사람으로 기록한다. 이전 감사의 중복 가능성 가설은 이 답으로 철회한다. 겹침 뒤 각 ID가 원래 사람을 계속 따라가는지, 팀·역할이 무엇인지는 이번 답으로 확정하지 않는다.

답은 기존 파일을 덮어쓰지 않고 work/human-labels/overlap-29-31-20261115.json에 저장했다. 원본 영상과 관측 trace의 SHA256 및 장면 범위로 한정한다. 다른 영상의 raw ID29/31에 일반화하지 않는다. tests/fixtures/distinct_overlap_29_31.json은 해당 답과 실제 상자 회귀 자료다.

현재 중복 제거를 실제 장면 상자에 재실행했을 때 제거 0건이며 ID29의 5개, ID31의 7개 관측 모두 보존됐다. 해당 장면에서 현재 필터가 잘못 제거하는 결함은 확인되지 않아 필터 임계값이나 알고리즘은 변경하지 않았다. 기존 stitch_tracks의 different_pairs 차단 기능에도 입력해 두 트랙이 합쳐지지 않음을 확인했다. 두 검증을 회귀 테스트로 추가했다.

모델 재학습, 전체 영상 자동 재연결, 운영 적용은 수행하지 않았다. 이 답 하나로 ID 교환률이나 일반화 정확도가 개선됐다고 주장하지 않는다. 후속 재연결 평가에서는 이 장면을 동일인 positive가 아닌 서로 다른 인물 negative로 사용해야 한다.
