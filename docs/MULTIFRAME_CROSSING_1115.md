# 여러 프레임 교차 판정과 확인된 ID 교환 수정

## 진행 결과
겹침 이전/이후 각 3개 깨끗한 관측에서 상·하체 외형 히스토그램과 양방향 운동 외삽을 비교하는 후보 판정을 구현했다. 외형/운동의 유지 또는 교환 선호가 일치하고 각 차이와 잔차 기준을 만족할 때만 후보를 낸다. 두 사람이 동시에 사라진 것을 한 사람으로 합치지 않는다. 후보 판정은 실제 신원 확정이 아니며 live 출력에는 연결하지 않았다.

appearance margin .08, motion margin .15, motion residual 최대1.5 상자높이, appearance instability 최대.15를 실험 전에 고정했다. 결과를 보고 임계값을 수정하지 않았다. 학습하지 않았고 평가 GT는 후보 선택에 넣지 않았다. 실제 사용 시 세 번째 후속 관측까지 기다려야 하며 과거 live 결과를 미리 맞혔다고 해석하면 안 된다.

## 실제 녹화
60초 기록에서 조건을 충족한 교차 17건. 같은 여러 프레임의 운동 비용만 비교하면 유지13/교환2/보류2. 외형·운동 합의 기준은 유지후보10/교환후보1/보류6이었다. 대부분 신원 정답이 없어 이 숫자를 정확도로 해석하지 않는다.

35초 ID563/748이 유일한 교환 후보이며 35.6초에 필요한 후속 관측을 확보했다. 사용자가 형광 조끼와 어두운 옷 선수의 ID가 서로 바뀌었다고 확인했다. 이 답은 후보 생성 후 받았고 학습·임계값 조정에는 사용하지 않았다. 확인된 교환 사례 1건을 찾은 것이며 전체 교환 탐지율이나 100% 정확도를 주장하지 않는다. 12.2초 ID29/31은 이미 서로 다른 사람이라는 답이 있지만 교차 전후 ID 유지 정답은 아니므로 보류를 유지한다.
