# 고정 광각 영상 전용 실험 미니맵

기본 설정은 꺼져 있다. `experimental_map: true`와 `validated: false`인 별도 보정 설정, 기준 프레임 `camera_guard_reference`, 특징점 영역 `camera_guard_feature_region`을 함께 제공해야 한다. 해상도가 같고 ORB 카메라 감시가 `stable`인 프레임에 한해, 저자가 제공한 기준점으로 사각형 내부에서 계산된 **실험 후보**만 낸다. 이 감시는 움직임이 없음을 보증하지 않는다. 105×68m는 이 예제의 좌표계 가정이며 실제 사용자 경기장의 실측값이 아니다. 보정 기준점 자체는 자동으로 찾은 것이 아니다.

11대11 가정에서는 관측 후보를 모두 보존하면서 단기 예측 후보만 합계 최대 22개가 되도록 최근 관측 순서로 제한한다. 관측 후보가 22개를 넘어가더라도 심판이나 오탐 가능성을 감추지 않고 전부 표시한다. 팀별 11명이나 선수 신원·역할이 확인된다는 뜻이 아니다. `capacity`의 `estimated_suppressed`, `observed_over_limit`에 제한 사실을 기록하고 화면에 알린다. 이 상태에서는 실험 피드백도 보류한다. 이 제한으로 재등장 연결이 개선되는지는 별도 정답 영상에서 검증해야 한다.

기존 로컬 라이브 분석 API의 서로 다른 시각 49개 응답에서 관측점만 뽑아 수정 전후 지도 상태기에 같은 입력을 넣었다. 수정 전후 최대 후보는 각각 20개였고 22개를 넘지 않아 제한이 실제로 발동한 응답은 없었다. 이는 정상 입력에서 관측 후보를 유지한 확인일 뿐, 과다 검출이나 ID 정확도가 실제 경기에서 개선됐다는 증거가 아니다. 22개를 넘는 입력은 자동 회귀 테스트에서 별도로 확인했다. 기록은 로컬 `work/field-like/roster-cap-live-audit-20261111.json`에 있다.

`/api/v1/analysis.experimental_map`은 별도 객체다. `status: reference_unverified`, `basis: manual_fixed_camera_reference`, `field_size_m` 및 `players`를 제공한다. `players` 원소의 `x,y`는 0~1 좌표, `team_hint` 0/1은 확정되지 않은 색상 A/B, `kind`는 실제 탐지 박스에서 계산한 `observed` 또는 잠시 사라진 이전 ID의 `estimated`다. `age_s`는 마지막 관측 이후 시간, `uncertainty_m:null`은 오차 범위가 아직 검증되지 않았다는 뜻이다. **기존 `players[].x/y`, 팀 확정, 경기 지표, 움직임, 확정 코칭에는 사용하지 않는다.** 별도 `experimental_feedback`은 이 실험 후보의 관찰과 한계만 표시한다. 실제 사람의 발점·역할·팀·ID 오류도 남는다.

화면의 실선 표식은 관측 박스에서 만든 실험 위치 후보, 점선 표식은 최근 두 관측 사이 속도를 연장한 짧은 예상이다. 마지막 관측 뒤 최대 0.8초까지만, 최근 두 점이 0.05~0.6초 간격이고 속도 크기가 가정상 12m/s 이하이며 예측 위치가 경기장 경계 안에 있을 때만 제시한다. 미디어 촬영 시각을 신뢰할 수 없는 로컬 MP4에서는 예상하지 않는다. 실제 SRT에서도 디코딩 시점으로 시간 차이를 잡으므로 네트워크 지연 변화·끊김에 따른 오차가 남는다. 중복 ID, 범위 밖, 지나친 속도, 오래된 입력, 카메라 가드 불일치 및 입력 재시작 시 보류한다. 로컬 테스트 재생목록이 `manual_tracks.reset()`을 호출하면 추정 이력도 즉시 무효화된다.

11대11은 각 팀에 선수가 최대 11명이라는 경기 조건일 뿐 실제 화면 밖 인원·위치의 정답이 아니다. 보이지 않은 ID를 만들어 채우지 않고, 화면에 있었던 추적 ID만 아주 짧게 예상한다. ID 전환이나 서로 가린 선수가 다시 나올 때는 틀릴 수 있다. 포지션도 자동 확정하지 않는다.

## 주석 기반 모의 가림 시험

같은 경기의 60~90초와 120~150초 CSV에서 주석 ID의 두 관측과 그 이후 주석 발점을 사용해 가림을 모의했다. 실제 가림, 탐지 누락이나 ID 교체를 넣지 않은 낙관적 실험이다. 원저자 제공 기준점으로 투영한 주석과의 상대 오차이며 GNSS 실측 오차가 아니다. 관측 간격 0.2초, 25fps 조건에서 0.8초 후 등속 예상 3,080건의 중앙 오차는 0.267m, p90 1.58m였다. 같은 표본에서 마지막 위치 고정은 중앙 1.83m, p90 3.60m였다. 주석 생성 과정의 보간과 같은 경기 상관관계가 결과를 좋게 만들 수 있다. 이 수치를 실제 경기 정확도나 개별 표식의 신뢰 구간으로 사용하지 않는다. 재현: `python scripts/evaluate_occlusion_candidates.py --calibration <보정후보.json> <동일경기_주석.csv> ...`

실제 영상으로도 기존 YOLO 후보·고정 카메라 감시를 사용해 실행했다. 71회 상태 샘플에서 실험 위치 후보가 최대 14명 나왔고, 검증 좌표와 코칭은 각각 0건을 유지했다. 위치 참값 대조나 실시간 SRT의 물리적 예측 오차 시험은 아니다. 재현 도구 `scripts/experimental_map_smoke.py`는 원본 영상·저자 기준점 및 가중치를 로컬 인자로 받으며, 실험 설정을 기존 설정에 쓰거나 모델을 배포하지 않는다.

실제 탐지 박스의 노이즈를 포함하는 별도 모의 실험도 추가했다. 같은 경기 60~90초 구간에서 4프레임 간격으로 실제 타일 탐지·추적한 뒤 주기적으로 모든 탐지를 가렸다. 마지막 관측에서 주석과 매칭된 ID만 보류된 미래 주석과 비교한 68건에서 등속 예상 오차 중앙 0.718m, p90 2.30m였고, 마지막 관측 위치 고정은 중앙 0.762m, p90 1.53m였다. 일부 큰 오차는 등속 예상이 더 나빴다. 이 역시 같은 경기·인공적 가림·기준점 투영 주석의 비교이며 실제 상대팀과 부딪히는 장면, ID 교체, 카메라나 통신 지연을 평가하지 않는다. `scripts/evaluate_detector_occlusion.py`로 로컬에서 재현할 수 있다.
