# 11대11 슬롯과 위치 상태

## 구현 범위
골키퍼를 포함한 팀별 11개 슬롯을 표시한다. 이는 사용자가 지정한 경기 인원 가정이며 실제 22명 신원 확인 결과가 아니다. 슬롯 번호는 등번호·포지션 번호가 아니다. 11명에 맞추기 위해 가짜 좌표를 생성하지 않는다. 퇴장·교체 등 실제 인원/명단 변경은 자동 처리하지 않는다.

같은 ID가 사라져도 슬롯은 남는다. 단기 예상 만료 후 좌표는 null이 된다. 같은 ID가 돌아오면 같은 슬롯에 표시한다. 기존 슬롯 ID가 사라진 상태에서 새 ID가 들어오면 동일 선수일 수 있어 빈 슬롯에 추가하지 않고 보류한다. 팀이 바뀐 동일 ID는 원래 슬롯을 팀·ID 확인 필요로 전환하고 반대편 슬롯에 복제하지 않는다. 중복 ID와 11명 초과 팀의 새 ID는 배정하지 않는다. 미분류 팀도 보류 항목에 포함한다. 새로운 세션 또는 시간 역행 시 슬롯을 초기화한다.

이 제한은 추적 ID를 실제 사람으로 확정하지 않는 장치다. 위치 후보는 기존 미니맵과 원본 목록에 남고 슬롯 대응 보류 수를 별도 표시한다. 11개 슬롯이 있다는 이유로 미니맵의 관측 후보를 실제 11명으로 확정하거나 임의 삭제하지 않는다. 기존 분류 답, 모델 가중치, 코칭 지표는 수정하지 않았다.

## 실제 재생 검증
같은 녹화 candidate의 60초를 15fps로 재생한 900시점에서 팀별 11개 슬롯과 미확인 좌표 null 불변식 위반 0건.
23초: 홈 관측 대응 1/위치 미확인 10, 상대 관측 대응 2/위치 미확인 8/팀·ID 확인 1. 관측 좌표 후보 15개(단기 예상 포함 화면 점 16개) 중 12개는 기존 슬롯과의 대응이 불확실하다. 보류가 많다는 점은 알고리즘 성공이 아니라 현재 ID 단절 한계다. 슬롯 틀의 구현과 22명의 지속 추적 성공을 구분해야 한다.

Node 테스트: 22슬롯, 단기예측→만료→복귀, 새 ID 보류, 팀 변경 충돌, 중복 ID, 팀 인원 초과, 세션 초기화. 기존 미니맵 예측 및 대시보드 DOM 테스트 통과. 훈련 답 및 운영 프로세스 미변경. 실제 브라우저 캡처/송출 검증 없음.

## 남은 작업
22명을 지속해서 대응하려면 동일 유니폼의 다른 선수 구별과 단절 ID 재연결 검증이 필요하다. 슬롯과 새로운 ID 대응을 사람에게 확인받는 기능은 이번 변경에 포함하지 않았다. 현재 보류를 자동으로 풀거나 예측을 장기간 늘려 실제 사람 대응이 확인된 것처럼 보이게 해서는 안 된다.
