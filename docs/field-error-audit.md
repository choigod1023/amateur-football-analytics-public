# 경기장 기준점 오류 분석

이 실험은 앞선 AI Hub Vss 개발 경기 프레임 200개에 같은 연구용 체크포인트를 다시 적용한 것이다. 원본은 1920×1080이며 데이터와 예측 프레임을 저장소에 포함하지 않는다. 이미 개발에 반복 사용한 경기의 상관된 프레임이므로 독립 검증이 아니고, 미터 단위 미니맵 위치 오차도 아니다.

프레임당 네 기준점 평균 오차 중앙값은 90.83px, p90은 168.43px이며 79/200프레임이 100px을 넘었다. 기준점별 오차 p90은 순서대로 196.65, 139.92, 173.24, 291.39px이다. 모든 정답점이 프레임 안에 있었으므로 이 평가에서 출력 좌표를 화면 내부로 제한하는 설계가 주된 오류라는 가설은 지지되지 않는다. 특정 기준점에 큰 오차가 집중되는 만큼 평균만 보고 정확하다고 판단할 수 없다.

두 가지 후보 개선을 같은 200프레임으로 시도했다. 프레임 ID 순서로 앞 100개에서 임계값·반경을 정하고 나머지 100개에서 비교했다. 같은 경기의 인접 또는 유사 프레임이 섞일 수 있어 별도 경기 테스트를 대신할 수 없다.

* 예측점 근처의 밝은 픽셀 거리로 보정 후보를 선별하면 뒤쪽 100프레임 중 46프레임만 남았는데 이 가운데 16프레임의 평균 오차가 여전히 100px을 넘었다. 전체 100프레임에서는 33프레임이 100px을 넘었다. 흰 유니폼과 조명 등도 밝으므로 신뢰도나 승인 조건으로 쓰기 어렵다.
* 밝은 영역의 코너 쪽으로 예측점을 이동하는 방법은 뒤쪽 100프레임의 중앙 오차를 86.59px에서 85.97px로 바꿨지만 p90은 172.36px에서 172.43px로 바뀌었고, 21프레임이 개선된 반면 30프레임은 악화됐다. 의미 있는 개선으로 보기 어려워 적용하지 않았다.

다음에는 서로 다른 경기·야간·아이폰 고정 촬영을 경기 단위로 나누고 직접 확인한 선·기준점 정답을 확보해야 한다. 예측 선 자체의 정확성과 영상 내 선수 발 위치의 미터 오차를 별도로 측정하고, 보정 오류 감지율을 최종 독립 경기에서 확인하기 전까지 자동으로 보정을 승인하지 않는다.
