# 기존 분류 답의 학습 누출 수정과 역할 분류 재검증

2026-11-15. 원래 평가로 지정한 장면 일부가 이후 학습 코드에서 다시 학습에 들어가는 결함을 확인했다. 이를 수정하고 동일한 학습 설정으로 분리된 실험을 실행했다. **평가 기준을 지킨 두 모델에서는 기존 어려운 장면 답을 추가했을 때 368/413 → 377/413으로 개선됐다.** 같은 경기에서 반복 사용한 개발 자료이므로 새로운 경기 일반화나 추적·미니맵 개선을 입증한 결과는 아니다.

## 확인한 결함

원본 답에는 `source_provenance.split`으로 train/eval/unassigned를 지정해 놓았다. 하지만 `train_team_role.load()`는 평가를 포함한 모든 사용 가능 답을 읽고, `retrain_reviewed_team.py`와 `retrain_capacity_answers.py`는 고정된 네 이미지 외의 모든 장면을 학습에 넣었다. 그 결과 원래 eval로 지정한 14개 이미지의 413개 사용 가능 답 중 **277개가 과거 방식의 학습 마스크에 포함**됐다.

이것이 과거 고정 네 이미지 자체에 대한 직접 누출을 뜻하지는 않는다. 고정 네 이미지 외에 별도로 지정한 평가 장면들이 학습에 들어가 원래 split 계약을 깨뜨렸다는 뜻이다. 어떤 배포 모델이 정확히 어느 답을 학습했는지는 기존 manifest가 불완전한 경우 확정할 수 없다.

수정한 세 학습 진입점은 명시적으로 `split=train`인 장면만 학습한다. eval/buffer_excluded/unassigned/누락/한 이미지 내 충돌은 제외한다. 고정 held-out 목록은 추가 제외로 유지한다. 다른 파일명으로 저장된 동일 이미지가 train/eval 양쪽에 있으면 SHA256으로 거절한다. 원본 분류 파일을 수정하지 않는다. `load()`는 평가 도구도 사용하므로 모든 관측을 읽는 역할을 유지하고, 학습 마스크를 별도로 반드시 적용한다.

## 실제 CPU 학습

- 기존 사람 답: 루트 역할 답 915개, 이미지 35개. 네 클래스 변환 후 사용 가능 876개.
- 클래스: 심판, 관중, A팀, B팀. 골키퍼는 소속 팀으로 합쳐진다. unknown/duplicate/shadow는 이 네 클래스 학습에서 제외된다.
- 평가: 원래 `split=eval`인 14개 이미지, 413개 답. 변경하지 않았다.
- 엄격한 시간 분리: 동일 `clip`의 평가 시각과 60초 미만인 훈련 장면 제외. 시간·clip 식별자가 없는 장면도 추정하지 않고 제외.
- 기준 모델: 일반 train 프레임 6개 이미지/207개 답.
- 후보 모델: 동일 기준에 이미 저장된 hard-case train 프레임을 추가해 13개 이미지/431개 답.
- 제외: 평가 이외 32개 답. unassigned 장면, clip 식별자나 시각이 빠진 최근 검토 답 등이 포함된다. 그 답을 삭제하거나 잘못된 답으로 취급한 것은 아니다.
- 기존 구조 고정: 24차원 특징, hidden=24, 500 epochs, seed 0·1·2 앙상블. GPU 사용 없음. 테스트 점수로 임계값이나 하이퍼파라미터를 고르지 않았다.

| 측정 | 깨끗한 기준 | 어려운 장면 답 추가 |
|---|---:|---:|
| 전체 정답 | 368/413 (89.10%) | 377/413 (91.28%) |
| 고정 confidence≥.5, margin≥.1로 응답 | 399 | 404 |
| 응답 중 정답 | 358/399 (89.72%) | 370/404 (91.58%) |
| 심판 정답 | 20/30 | 23/30 |
| 관중 정답 | 95/108 | 95/108 |
| A팀 정답 | 126/136 | 130/136 |
| B팀 정답 | 127/139 | 129/139 |

원래처럼 평가 답 일부를 학습한 진단 모델은 401/413(97.09%)이었다. 이 숫자는 누출된 결과이므로 위 두 모델보다 우수하다는 근거로 사용하면 안 된다. 과거 운영 모델과 새 모델의 공정한 전후 비교도 아니다.

후보는 관중 108명 중 95명만 관중으로 구별했고, 남은 13명 중 4명을 선수로 분류했다(기준은 3명). 팀·심판 개선만으로 관중 유입까지 해결됐다고 주장할 수 없다. 실제 선수 탐지기의 누락·상자 오차, 동일 유니폼의 개인 구별, 미니맵 좌표, 코칭 정확도는 이 실험에서 측정하지 않았다. 운영 모델은 바꾸지 않았다.

## 운영 전 남은 일

학습 코드의 split 결함은 수정됐지만 이미 평가에 반복 사용한 자료를 다시 새로운 독립 시험으로 만들 수는 없다. 아직 검토·학습에 쓰지 않은 촬영 구간을 별도로 고정해야 한다. 최근 사람 답은 source clip 식별자가 없어서 엄격 실험에서 보류됐으므로, 원본 장면과의 대응을 증명한 후 파생 manifest에서 보완해야 한다. 사용자가 같은 역할을 다시 입력할 필요는 없다.

이 네 클래스 모델은 골키퍼를 별도 역할로 내보내지 못하며, shadow/duplicate 답을 그대로 학습하지 않는다. 이 답들은 탐지의 오탐·중복 평가에 활용해야 한다. 색상 분류 정확도 상승을 선수 신원 추적 성공으로 바꾸어 보고해서는 안 된다.
