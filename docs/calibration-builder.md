# 수동 기준점으로 보정 후보 만들기

기존 `capture_calibration_frame.py`로 영상의 실제 원본 프레임을 먼저 저장한다. 영상과 실제 경기장에서 같은 선 교차점을 찾고, 프레임 픽셀과 현장에서 측정한 경기장 좌표(미터)를 각각 입력한다. 아래 숫자는 입력 형식 예시일 뿐 실제 영상의 좌표가 아니다. 경기장 크기와 좌표 원점·방향은 실제 경기장에 맞게 통일한다. fitting_points를 4~20개 지정하고 그와 다른 지점들을 checkpoints에 기입한다.

```json
{
  "image_size_px": [1920, 1080],
  "field_size_m": [100, 50],
  "fitting_points": [
    {"image_point": [100, 100], "field_point_m": [0, 0]},
    {"image_point": [1800, 100], "field_point_m": [100, 0]},
    {"image_point": [1800, 950], "field_point_m": [100, 50]},
    {"image_point": [100, 950], "field_point_m": [0, 50]}
  ],
  "checkpoints": [
    {"image_point": [950, 525], "field_point_m": [50, 25]}
  ]
}
```

```powershell
.venv\Scripts\python.exe scripts\build_calibration.py <측정값.json>
```

입력 순서는 무관하다. 도구는 영상에서 면적이 가장 넓은 유효 사각형을 선택하므로 선택된 원래 입력 인덱스와 사용되지 않은 입력 인덱스를 함께 출력한다. 체크포인트를 설정하면 기존 평가 도구로 해당 지점들의 오차와 보류 사유를 출력한다. **항상 `validated: false`인 보정 후보를 출력**하며 설정을 자동 수정하거나 위치 출력을 켜지 않는다. 선택 면적이 넓다는 것은 보정이 정확하다는 증거가 아니다. 사용되지 않은 피팅 입력점도 검증점으로 자동 취급하지 않는다.

`unused_fitting_consistency`는 피팅 후보 중 선택되지 않은 점이 결과와 얼마나 맞는지 보여주는 진단이다. 사각형 선택에 관여했으므로 독립 정확도가 아니다. 영역 밖 점은 측정하지 않고 보류하며 오류 0으로 세지 않는다. 일치하지 않는 점이 있으면 마킹, 렌즈 왜곡, 경기장 크기를 다시 확인한다. 독립 체크포인트 보고서는 별도로 필요하다.

독립 검증점은 피팅에 사용하거나 사용 후보로 넣은 점과 다른 여러 지점으로 따로 측정한다. 보정 영역 밖의 검증점은 오차가 아니라 보류로 표시된다. 오차 허용치는 사용 목적과 측정 정밀도에 따라 정하고, 고정 구도·해상도·렌즈 왜곡·실제 필드 치수를 확인한 뒤 사용자가 승인 여부를 판단한다. 카메라가 움직이면 다시 보정한다. 이 도구는 경기장 선이나 선수 발 위치를 자동 탐지하지 않는다.

## 공개 데이터 시험

SoccerNet SN-Calibration-2023 연구용 검증 자료에서 201개 주석을 간격 표본 추출했다. 경기장 선 교차점 5개 이상을 찾은 103장 중 29장은 유효한 보정 사각형을 만들지 못했다. 남은 74장 중 선택한 검증점이 영역 밖인 23장을 보류했고, 출력된 51개 점의 오차 중앙값은 0.302m, 90백분위는 0.878m였다. 기준점과 검증점은 같은 선 주석을 공유하고 실제 선수 위치 정답이 없으므로 독립적인 현장 정확도가 아니다. 자동 기준점 탐지, 카메라 이동 및 아이폰 환경도 시험하지 않았다. 학습이나 운영 반영에는 사용하지 않았다. [SoccerNet 자료](https://huggingface.co/datasets/SoccerNet/SN-Calibration-2023)는 연구용이며 [공식 FAQ](https://www.soccer-net.org/faq)는 상업적 이용을 허용하지 않는다.
