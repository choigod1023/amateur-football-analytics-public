# 사람 답을 반영한 실제 재학습

## 자료와 방법

사용자 분류910개·31장을 점검했다. 현행4분류(referee,spectator,team_a,team_b)에 사용할 수 있는 답871개 중735개를 학습,136개·4장을 평가에 사용했다. 학습은 기존732개에 이번 직접 확인3개를 추가했다. 같은 사람 답에서 파생한 답은 이번 학습에 추가하지 않았으므로 직접 답과 섞이지 않는다.

기존 `split=eval` 표기 중 일부가 과거 학습에 사용된 이력이 있어 표기만으로 분할하지 않았다. 기존 모델의 per_scene 목록에 없는 b04와b11의4장을 후보와 대조 모델에서 통째로 제외했다. 기존136개 평가 수와 정확도를 재현했지만 최초 명세가 없으므로 과거 학습 배제는 완전히 증명할 수 없다. 이번 실험에서는 이미지·정답 SHA256과 분할 명세를 기록했다. 네 사진은 두 시간 구간이며136개의 독립 경기 표본이 아니다.

은닉24,500epochs,3seeds 앙상블을 그대로 사용했다. 기존732개만 사용한 matched_baseline과735개를 사용한 candidate를 동일 조건으로 학습했다. 평가 결과에 따라 파라미터를 반복 조정하지 않았다. 이 작은 색상·상자 특징 모델의 학습은CPU에서 수행했고, 실제 영상 탐지는GPU에서 실행했다.

matched_baseline은 기존 모델과 같은 혼동행렬을 재현했다. 심판10/11,관중35/39,A팀39/43,B팀41/43으로 후보의 역할별 정답 수 역시 같았다. 확신 기준은최대확률0.5이상·차이0.1이상이다. 현재 라이브 누적투표와 동일한 평가 단위가 아니므로 이 숫자를 라이브 정확도로 해석하지 않는다.

이번 직접 답3개 중 모델은 학습 전후 모두2개를 맞혔다. d0107의 A팀 사례는 후보도B팀 확률0.710으로 오분류했다. 확대 영상에 겹친 두 사람이 보여 상자 기반 상체 특징의 한계 가능성이 있으나, 사용자 답을 바꾸거나 평가에서 제외하지 않았다.

## 저장과 운영

모델과 원시 결과는 `work/team-role-retrained-20261113/`에 저장했다. `candidate.pt`, `matched_baseline.pt`, `manifest.json`, `metrics.json`, `replay-comparison.json`, 두 모델의 관측JSONL·로그가 있다. 기존 모델과 사용자 정답은 변경하지 않았다. 모델 후보는 운영 모델로 교체하지 않았다. 개선 근거가 한 경기의 짧은 구간에 한정되기 때문이다.

재현 도구는 `scripts/retrain_reviewed_team.py`, `scripts/compare_team_replays.py`다. 출력 폴더/보고서 덮어쓰기를 거부한다. 분할과기존 위치/추적 관련 회귀 테스트7개 통과. 모델/영상/개인 분류 답은Git에 포함하지 않는다.

다음 작업은 새 답을 더 반복 학습하는 것보다 겹침에서 어느 상자가 어느 사람인지 추적하는 특징과 원거리 발 위치의 안정성을 개선하는 것이다. 이미 답한 사진을 재질문하지 않는다.
