# AI Hub 선 분할 추가 학습 — 개발 실험

기존 `work/field-auto-train/segmentation-experimental.pt` 선 분할 모델을 같은 q6c 학습 경기의 500프레임에서 AdamW 학습률 0.0001로 5 epoch 추가 학습했다. GPU RTX 5070을 사용했다. Vss 별도 개발 경기 100프레임, 주석된 선 종류 339개에 대한 기존 점수는 픽셀 정밀도 15.71%, 재현율 32.31%였고, 추가 학습 후 13.45%, 35.20%였다. 두 결과는 같은 난수 시드와 자료 추출 경로를 사용했다. 픽셀 정밀도와 재현율은 선별한 주석 채널에만 적용되며, 빠진 선 종류에 대한 오탐은 측정하지 않는다.

선 재현율과 정밀도가 교환되었으므로 정확도가 향상되었다고 볼 수 없다. 각 분할이 단일 경기이며 인접 프레임이 상관되어 있고 개발 경기 역시 이전부터 반복 활용했기 때문에 독립 최종 성능이 아니다. 이 결과에는 선 교차점 정확도, 미터 위치 오차, 미니맵과 실제 코칭 정확도도 포함되지 않는다. 체크포인트를 서버에 연결하지 않았으며 기존 모델을 대체하지 않았다.

기존 권한 자료가 준비된 환경에서 `..\football-coach-server\.venv\Scripts\python.exe scripts\experimental_field_segmentation_resume.py`로 실행한다. 결과와 체크포인트는 `work/field-segmentation-resume-1111`에 생성되며, 실수로 덮어쓰지 않도록 이미 경로가 있으면 실행이 거부된다. 다른 결과를 생성하려면 코드를 복제해 별도 출력 경로를 지정한다. 원본 이미지와 가중치는 이용 권리 제한에 따라 저장소에 포함하지 않는다.
