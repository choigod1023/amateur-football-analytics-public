# 고정 경기장 구도 적응 시험

## 범위와 운영 상태

기존 기준 사진과 경기장 보정을 재사용하는 선택형 CLI 기능이다. 완전 자동 경기장 선 인식이나 물리적으로 이동한 카메라의 정확도 보장은 아니다. 운영 서버에는 활성화하지 않았으며 SRT·녹화 서버를 재시작하지 않았다.

사용자 요청대로 cam1 89×62m, cam3 89×60m의 저장값을 각각 유지한다. 실측값이 아니므로 metre 정확도는 미검증이다. 기존 분류와 보정 파일을 수정하지 않는다.

## 구현

- `--camera-adaptation`: 원본 기준 사진에 매번 직접 정합하여 누적 드리프트를 피한다.
- 경기장 영역 특징점, 상호 일치, RANSAC, 분산 범위, 별도 검증점 오차, 기하 검사를 통과해야 한다.
- 연속 두 분석 프레임에서 안정된 변환을 얻은 뒤 위치 계산을 재개한다.
- 실패하거나 움직이면 이전 위치를 재사용하지 않고 전술 이력을 초기화한다. 지원 영역 밖 발 위치는 보류한다.
- 실패 장면 하나를 실행별로 동결 저장한다. 기존 `/train` 검토 저장소를 지정하면 사람이 기준점 4개 이상을 넓게 지정할 수 있다.
- 사람이 새 보정을 저장한 뒤 해당 분석 CLI를 재실행해야 한다. 자동 재읽기는 구현하지 않았다.
- `<alerts>.camera.json`에 보류 원인, 검토 토큰, 추정 치수, 정합 상태를 쓴다. 이 sidecar는 대시보드의 새 실시간 상태 API로 연결하지 않았다.

## 재현

프로젝트 가상환경 Python으로 실행한다.

```text
python -m pytest -q
python scripts/evaluate_camera_adaptation.py ../../work ../../work/camera-adaptation-eval-20261113/new-result.json
python scripts/run_live_feedback.py VIDEO CALIBRATIONS cam3 --direction 1 --team B --detector WEIGHTS --classifier CLASSIFIER --camera-adaptation --analysis-fps 5 --store REVIEW_STORE --session UNIQUE_SESSION
```

`VIDEO`, 모델·분류기 경로, 저장소 및 보정 JSON 경로는 실제 파일로 지정한다. 보정 기준 사진은 저장소의 `pending/<ref_token>.jpg`에 있어야 한다. 평가 출력은 기존 파일을 덮어쓰지 않는다. `--reference-bg` 및 수동 `--shift`와 적응 옵션을 함께 쓰지 않는다.

## 확인한 결과

실제 녹화 영상에 알려진 영상 변환을 적용하고 독립 51점으로 검사했다. 이동·확대/회전·원근 변환의 중앙값 오차는 각각 0.754, 0.123, 0.324px였다. 이는 합성 영상 좌표 시험이며 실제 경기장 metre 오차가 아니다.

실제 녹화 1800·2100·2600초 정지 화면 중 2600초만 정합을 통과했다. 다른 저장 각도 cam1, 빈 화면은 보류했다. 표본 3장으로 일반 정확도를 주장할 수 없다.

실제 GPU 탐지·분류·보정을 포함한 2초 구간 시험:

| 구간 | 분석 프레임 | 보정 승인 | 팀과 위치 모두 승인된 선수 평균 | 코칭 |
|---|---:|---:|---:|---:|
| 2600초부터 | 10 | 6 | 0 | 0 |
| 1800초부터 | 10 | 0 | 0 | 0 |

두 시험 모두 종료까지 실행됐고 종료 상태에서 코칭이 비활성화됐다. 초기 GPU 시험에서 발견한 numpy bool의 JSON 직렬화 오류는 수정하고 회귀 테스트를 추가했다.

최종 전체 테스트 423개 통과, 1개 건너뜀. 기존 검토 저장소 JSON 1,174개를 SHA-256으로 비교해 변경이 없음을 확인했다.

## 남은 작업

야간 잔디의 특징점 부족과 구도 차이에 따른 보류가 많다. 승인률을 높이기 위해 임계값만 완화하지 않는다. 복수 기준 사진과 경기장 선·교차점 후보를 도입하고, 사람이 지정한 별도 검증점을 이용해 metre 오차를 확인해야 한다. 추적/팀 투표 초기화로 짧은 승인 구간에서 분류가 준비되지 않는 문제도 긴 영상으로 분리 측정해야 한다. 이번 변경은 추적 정확도나 코칭 정확도 향상을 입증하지 않는다.

이번 시험의 검토 장면은 운영과 분리한 시험 저장소에 저장했다. 공개 페이지에 새 질문을 배포했다고 주장하지 않는다. 실제 치수는 미확인이며, 사용자 요청에 따라 기존 추정값으로 진행한다.
