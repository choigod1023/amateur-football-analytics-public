# 공개 검수 페이지

`app.review_public`은 저장된 화면 한 장을 검수하는 독립 서비스다. 라이브 수신·분석 서버를 실행하거나 재시작하지 않는다. 시제품이라 HTTP와 무인증으로 만들어져 있다. 공개 배포 전에는 인증을 추가해야 한다. 명시적으로 공개하기로 한 자료만 사용한다.

다른 프로세스가 동시에 사용하는 라벨 저장소는 프로세스 간 잠금이 없으므로 공유하지 않는다. 원본 화면과 필요한 기존 라벨을 새 전용 디렉터리에 복사하고, 이 서비스의 유일한 쓰기 대상으로 사용한다. 전용 저장소의 답변은 원본 저장소에 자동 병합되지 않는다. 자동 시작이나 방화벽 변경은 하지 않는다.

필수 환경변수는 `FOOTBALL_REVIEW_DIR`(이미 존재하는 절대 경로), `FOOTBALL_REVIEW_ORIGIN`(정확한 외부 HTTP 원점)이다. `FOOTBALL_REVIEW_BIND`와 `FOOTBALL_REVIEW_PORT`는 기본값 `127.0.0.1`, `8443`이다. `python -m app.review_public`으로 실행한다. 외부 공개는 사용자가 선택한 네트워크 설정이 별도로 필요하다.

관중은 사람 검출을 위한 배경 음성으로 취급하지 않는다. 그림자·사물은 배경 후보이며, 중복 상자는 제거 대상으로 저장한다. 추론되지 않은 선수는 화면에서 직접 상자를 그리고 역할을 확정할 수 있다. 저장은 학습이 아니며 해당 프레임은 부분 주석이므로 전체 프레임의 완전한 탐지 정답으로 취급하지 않는다.

`python -m scripts.export_review_crops --labels <전용_저장소> --output <새_디렉터리>`는 사람이 확정한 역할별 크롭과 메타데이터를 내보낸다. 중복과 미확인은 제외하며 분할은 `unassigned`로 남는다. 별도 경기 단위의 학습·평가 분할과 재학습·정확도 평가가 필요하다. 그림자 크롭에도 다른 미주석 인물이 포함될 수 있다.
