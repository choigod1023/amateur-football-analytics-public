# 확인 전 유니폼 색상 그룹 힌트

`suggest_team_clusters: true`를 설정하면 처음 10개 분석 프레임의 사람 추적 상의 색상만으로 두 그룹을 만들고 이후 분석 API의 각 사람에 `suggested_color_group`을 `0`, `1`, 또는 `null`로 표시한다. 대시보드는 0/1을 미확인 색상 후보 A/B로 표시하며 `home`/`away`나 역할을 자동 지정하지 않는다. 수동 확인 모드에서는 같은 분석 프레임 스냅샷에도 후보가 포함된다. 충분히 다른 네 개 이상의 추적 ID와 각 그룹 두 개 이상의 ID가 없으면 결과를 내지 않는다. 첫 입력 때마다 새 그룹을 만들고 입력 중에는 고정한다. 영상 내 선수·심판·골키퍼 모두 학습에 섞일 수 있고 조명·카메라 변화와 ID 전환이 있어 그룹은 틀릴 수 있다.

**그룹 번호는 팀, 역할, 홈/원정 또는 우리 팀의 정답이 아니다.** 사용자가 같은 스냅샷 이미지를 보고 각자의 역할과 팀을 확인하기 전에는 `team`이 unknown이며 지표·코칭에 포함되지 않는다. 골키퍼·심판을 후보 그룹에 넣지 말라는 뜻이 아니다. 모델은 이들을 인식하지 못하므로 후보 그룹에 실제로 들어갈 수 있다. 두 팀 구분이 어려운 구도·유니폼·야간에서 결과를 무시해야 하며, 동일 색상의 동료라도 사전에 동의 없이 일괄 확정하지 않는다. 수동 확인은 10초·연속 ID 유지 조건과 기존 오류 처리를 따른다.

AI Hub 실제 경기 781의 연속 50프레임 중 최초 10프레임으로 만들고 이후 40프레임의 YOLO+ByteTrack 정답 선수 매칭을 확인했다. 정답으로 그룹↔팀의 방향을 사후 최적 선택한 낙관적 조건에서 선수 369건 중 일치 343, 오분류 14, 보류 12였고, 비선수 26건에는 모두 그룹이 표시됐다. 318경기의 같은 조건에서는 선수 83건 중 80/0/3이었다. 동일 선수의 반복 프레임이며 선수가 아닌 미매칭 탐지도 그룹화되어, 역할/현장 정확도나 실시간 지연은 검증되지 않았다. AI Hub 원본과 라벨은 이용 조건에 따라 로컬에만 보관한다. 자동 모델은 정답을 학습 입력으로 쓰지 않았다.

AI Hub MP4 120프레임을 실제 서버 `run`에 넣고 수동 모드에서 확인되지 않은 스냅샷에 색상 그룹이 나타나도 팀은 모두 unknown이며 피드백이 생기지 않음을 확인했다. 이 시험은 사용자 클릭, 맥북, 외부 SRT의 검증이 아니다. 유니폼 후보를 안정적인 팀 분류로 사용하기 전에 독립 경기·야간·심판/GK·추적 ID 오류 및 실제 사용성 평가가 필요하다.

## 색상이 다른 사람에 대한 보류 실험

기존 분류기는 두 그룹 중 어느 쪽에 상대적으로 가까운지만 비교했다. 781경기에서 비선수 매칭 26건 모두에 그룹을 부여했으며, 가장 가까운 중심까지의 색상 히스토그램 거리 중앙값은 0.864였다. 정답 선수 중 기존 그룹과 일치한 343건의 중앙값은 0.165였다. 상대적 차이만으로는 어느 그룹에도 닮지 않은 사람을 걸러낼 수 없다.

이 거리도 0.4 이하여야 후보를 표시하도록 바꿨다. 0.4는 781·318 영상 결과를 살펴본 뒤 정한 실험값이며 확률이나 신뢰도 보증이 아니다. 같은 10프레임으로 그룹을 만들고 나머지 40프레임의 실제 YOLO/ByteTrack 탐지를 IoU 0.5 이상 정답 박스와 일대일 매칭해 바꾸기 전과 후를 비교했다. 평가 구간의 정답으로 두 그룹 번호와 두 팀의 대응을 사후 선택한 낙관적인 조건이다. 310은 거리 제한 선택에 사용하지 않은 추가 경기지만 이 프로젝트에서 과거에 사용된 자료이므로 최종 독립 평가가 아니다.

| 경기 | 선수 일치 전→후 | 선수 오분류 전→후 | 선수 보류 전→후 | 비선수에 그룹 표시 전→후 | 미매칭 탐지에 그룹 표시 전→후 |
|---|---:|---:|---:|---:|---:|
| 781 | 343→318 | 14→12 | 12→39 | 26→0 | 10→7 |
| 318 | 80→62 | 0→0 | 3→21 | 0→0 | 117→38 |
| 310 | 316→296 | 0→0 | 1→21 | 7→0 | 33→3 |

미매칭 탐지는 주석이 없거나 매칭에 실패한 선수일 수도 있다. 같은 선수의 연속 프레임이 반복되므로 표의 건수를 서로 독립된 사례로 볼 수 없다. 새 기준은 일부 틀린 후보를 보류하는 대신 올바른 후보도 더 많이 보류한다. 심판이나 골키퍼가 실제 선수와 비슷한 색을 입으면 여전히 그룹이 붙을 수 있고, 색 후보는 역할을 판정하지 못한다. 관측 초반 10프레임에 충분한 사람이 없어 그룹 만들기에 실패한 경우 이후 10프레임 단위로 다시 시도하도록 수정했다. 그룹이 만들어진 후에는 이전처럼 고정한다. 야간, 카메라 변화, 유니폼 색이 비슷한 팀, ID 전환과 현장 실시간 성능은 별도 검증이 필요하다.

AI Hub 이용 조건을 준수해 영상과 주석을 로컬에 둔 상태에서 다음 명령으로 각 경기를 다시 계산할 수 있다. 세 자료의 시작 프레임은 모두 900이고 `--device cpu`도 사용할 수 있다. 두 알고리즘이 동일 모델·설정으로 추적을 각각 실행하므로 비결정적 추론 환경에서는 결과가 달라질 수 있다. 정답은 학습이나 후보 생성에 넣지 않으며, 평가 매칭과 사후 팀 대응에만 쓴다.

```powershell
python scripts/evaluate_team_suggestions.py --video 경로.mp4 --labels 주석.json --weights yolo11n.pt --device cuda:0 --start 900
```
