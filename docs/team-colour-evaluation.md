# 팀 색상 분류 예비 비교

기존 전체 상반신 픽셀 중앙값은 작은 선수 박스에서 잔디가 많은 경우 흰색·파란색 유니폼이 묻힐 수 있다. 보수적 pixel support 후보는 유니폼 기준 색에 가까운 픽셀과 주변 픽셀의 비율을 비교한다. 이 방법은 임계값 규칙으로, 선수 분할·역할 구분·조명 보정을 학습한 모델이 아니다. 기본 분류기를 바꾸지 않으며 명시적으로만 사용한다.

[SoccerTrack v1](https://github.com/aemis2024/SoccerTrack) 동일 경기 0~30초 첫 프레임에서 시각적으로 흰색 10명·파란색 9명을 확인하고 유니폼 참고 HSV를 `[0,0,150]`, `[110,210,75]`로 지정했다. 일부 그룹 번호는 실제 팀과 달라 첫 화면의 외형과 ID를 대조했으며 골키퍼와 공은 제외했다. CSV 번호와 실제 프레임 정렬·숨은 선수·역할을 완전 검증하지 않았고 개별 영상의 라이선스도 확인되지 않았다.

같은 경기의 다른 시간 60~90초, 120~150초에서 각각 6프레임의 제공 박스와 첫 프레임에서 육안 확인한 ID를 비교했다. 기준 228개 박스 중 기존은 34개 일치·20개 반대 팀·174개 unknown, 후보는 15개 일치·0개 반대 팀·213개 unknown이었다. 이는 같은 경기·카메라·중복 선수이고 일부 라벨이 부정확할 수 있어 일반화된 정밀도 또는 독립 경기 정확도가 아니다. 후보는 오분류 가능성을 줄이는 대신 대부분을 보류했다.

다른 경기인 MUVY 이벤트 05의 000091 프레임에서 별도로 육안 표시한 사람 중심점과 기존 YOLO 검출 박스를 일대일 대응해 비교했다. 경기 전체를 검수한 정답은 아니며 이 프레임을 바탕으로 밝은색 `[0,35,235]`와 어두운색 `[80,110,100]`을 잡았다. 16명 표시 중 3명은 탐지되지 않았다. 탐지된 밝은색 8명에서 기존 6명·후보 2명이 분류됐고, 탐지된 어두운색 6명에서 기존 0명·후보 5명이 분류됐다. 나머지는 unknown이다. 같은 프레임에서 참고색을 정한 매우 작은 표본으로, 최종 시험이 아니다. 해당 경기의 흐린 다른 프레임에서는 표시된 13명을 모두 놓쳐 팀 분류 자체를 비교하지 못했다.

기준색 자동 추출과 사용자가 클릭해 보정하는 기능은 없다. 여러 독립 경기·야간·비슷한 유니폼·심판과 골키퍼·서로 가린 장면에서 별도 라벨을 정하고 선택된 분류의 정확도와 unknown 비율을 함께 측정하기 전에는 실시간 전술 지표를 신뢰할 수 없다. 자동으로 확인 여부를 true로 설정하지 않는다.

## 추가 보류 장면과 경계 조건 점검

`guarded_palette`는 상자가 영상 밖으로 잘리거나 비교할 주변의 밝은 픽셀이 30개 미만이면 색이 비슷하다는 증거가 없어도 팀을 지정할 수 있었다. 이제 이 경우 `unknown`으로 보류한다. 이 변경은 선택형 분류기에만 적용되며, 중앙값 분류기와 운영 설정은 그대로다. 어두운 배경, 잘린 상자, 배경이 전혀 없는 전체 화면 상자를 포함한 합성 사례로 전후 동작을 점검했다. 선수와 심판을 구분하는 기능은 여전히 없다.

기존 SoccerTrack 동일 경기 후반 12개 샘플의 228개 제공 상자와 기존 임시 ID 기반 팀 표기를 다시 비교했다. 중앙값 방식은 일치 34, 반대 팀 20, unknown 174였고 선택형 방식은 변경 전후 모두 일치 23, 반대 팀 0, unknown 205였다. 이전 기록의 후보 일치 15와 다르므로 당시 환경 또는 평가 차이를 해소하기 전 직접 비교하지 않는다. 제공 상자와 반복 선수, 불완전한 임시 ID 대조이므로 독립 검증 정확도가 아니다. 이번 경계 조건 변경 자체는 이 표본의 분류 수를 바꾸지 않았다.

추가로 MUVY 05·07의 부분 수동 중심점 4장, YOLO11n 1280/confidence 0.35 CPU 탐지 상자를 비교했다. 중심점과 상자가 일대일로 대응되는 선수만 계산하고, 골키퍼·심판·역할 불명과 겹친 상자는 제외했다. 경기별 대략적인 참조 HSV를 사용했으며 특히 05의 참조색은 평가 장면을 참고했다. 05/07이 독립 경기인지 확인되지 않았다. 46개 표시 중 34개는 탐지 실패 또는 대응 불명확이었다. 나머지 12개에서 중앙값은 일치 6·반대 팀 2·unknown 4, 선택형은 일치 6·반대 팀 0·unknown 6이었다. 아주 작은 부분 표본이며 한 중심점을 덮었다고 정확한 선수 상자가 보장되지 않는다. 탐지되지 않은 선수, 오탐과 심판 오분류는 이 분모에 포함되지 않는다. 두 영상의 개별 이용 권한은 확인되지 않아 연구 목적으로만 사용하고 재배포하지 않는다.

재현 예: 프로젝트 루트에서 `python scripts/evaluate_team_partial.py --work <work 경로> --weights <yolo11n.pt 경로>`. 부분 수동점과 원본 프레임은 별도 보관되며 저장소에 포함되지 않는다. 추후 사용 권한이 명확한 여러 야간 경기에서 경기 단위로 분리하고 팀·역할·박스 정답을 독립 검수한 후 실제 오분류, 누락 및 unknown을 함께 측정해야 한다. 이 결과만으로 기본값 변경이나 자동 팀 검증을 허용하지 않는다.
