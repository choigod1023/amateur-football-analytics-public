# 선수 역할 미확인에 따른 코칭 보류

상의 색이 비슷한 심판과 골키퍼를 필드 선수로 처리하거나 상대 선수를 잘못 분류하면 관측 범위의 최솟값과 최댓값이 바뀌어 폭·길이와 피드백이 왜곡된다. 현재 사람 탐지기는 역할을 판별하지 못한다. `team_classification_validated`는 유니폼 색상의 검증 여부이며, 사람의 역할까지 검증했다는 뜻이 아니다. 따라서 자동 색상 분류는 참고용이고 지표 및 코칭에는 사용하지 않는다. 필드 선수와 팀을 관찰자가 직접 확인한 ID는 수동 확인 모드에서 계속 사용할 수 있다.

기존 실제 경기 프레임 46장 실험에서 역할을 모두 선수라고 위험하게 가정하고 실험용 색상 분류를 사용했을 때 35장에 피드백이 나왔고 그중 11장에 상대 팀, 비선수 또는 정답과 매칭되지 않은 탐지가 섞였다. 매칭되지 않았다고 반드시 탐지 오류인 것은 아니다. 같은 입력과 검증되지 않은 역할에 대한 보류 규칙으로 다시 실행했을 때 35장 모두 피드백이 보류됐다. 이는 오염 가능성을 줄이는 대신 관측 24장도 포기한 것으로, 자동 인식 정확도나 코칭 성능이 향상됐다는 뜻은 아니다.

이 비교는 한 경기의 비연속 프레임, 수동/정답 기반 프레임별 보정, 정답 기반 유니폼 표본과 105×68m 가정, 실험 전용 팀 분류를 사용했다. 독립 경기·야간·아이폰 실시간 영상에서 성능을 보증하지 않는다. 별도로 검증된 역할 분류기가 생기면 가림과 추적 ID 전환까지 포함해 독립 영상에서 평가한 뒤 자동 지표의 재개를 검토한다.
