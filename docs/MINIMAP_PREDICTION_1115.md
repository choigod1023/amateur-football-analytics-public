# 단기 미탐 이동 예측 검증

## 구현
최근 연속 3개 동일 팀·ID 관측의 2개 속도를 평균한다. 추정 경기장 크기 89×60m 기준 속도가 12m/s를 넘거나 두 속도 벡터 차이가 4m/s를 넘으면 예측하지 않는다. 속도를 시간상수 0.6초로 감쇠하며 마지막 관측 후 0.8초 이내에서만 예측한다. 최근 이동이 불안정하거나 부족하면 기존 짧은 마지막 위치 표시로 돌아간다.

예측은 빈 원·시간에 따라 커지는 범위·투명도로 표시한다. 범위는 0.5+3×경과초(m)라는 휴리스틱이며 신뢰구간이나 보장된 실제 오차가 아니다. 주변의 현재 탐지나 이미 추가한 예측과 0.025 정규좌표 이내로 겹치면 숨긴다. 팀 인원 한도와 카메라 보정·세션 초기화·만료 규칙은 유지한다. 원본 관측값과 코칭 입력은 변경하지 않는다. 동일 ID의 재관측만 화면에서 잇고 새 ID의 동일인 재연결은 구현하지 않는다.

UI 상태 구분은 unslop(Damir Sokolovsky, @heydamir, CC BY 4.0)의 원칙을 참고했다.

## 실제 관측값 재생 결과
두 입력은 같은 60초 녹화 영상에 대한 baseline/candidate 모델 결과로 독립 경기 두 개가 아니다. 학습과 정답 판정에 사용하지 않았다. web/minimap-motion.js의 이전 버전 88f63ad와 현재 버전을 동일 입력에 적용했다.

|항목|candidate|baseline|
|---|---:|---:|
|동일 ID 재관측 비교 수|58|32|
|마지막 위치→재관측 평균 거리|1.944m|1.846m|
|예측 위치→재관측 평균 거리|1.811m|1.540m|
|예측이 가까워짐 / 멀어짐|38 / 20|25 / 7|
|표시 사라짐 전→후|136→137|185→185|
|팀 인원 초과 프레임 전→후|26→26|155→155|

재관측 위치와 동일 ID 자체가 오차를 가질 수 있으므로 실제 위치 정확도나 ID 정확도 증거가 아니다. 사용자 정답은 변경하지 않았다. candidate에서 15fps로 평가한 연속 예측 495구간의 최대 이동은 프레임당 0.312m, 최대 속도 4.681m/s였다. 제한된 예측 구간에서 부드러운 이동을 확인하는 수치이며 전체 궤적 점프가 없다는 뜻은 아니다. 장기 미탐과 관측 ID 변경, 중복 관측은 여전히 남는다.

## 프리뷰와 검증
work/minimap-motion-prediction-20261115/prediction-comparison.mp4: 실제 녹화 12~38초에 대한 15fps 합성 비교 영상. 왼쪽은 마지막 위치 정지, 오른쪽은 예측. 실제 브라우저 캡처가 아니다. 같은 미니맵 JS 출력으로 렌더링했다. 관측과 예측을 구분하며 예측 위치를 확정 코칭에 사용하지 않는다.

Node 경계 테스트: 감쇠 이동, 시간에 따른 범위 증가/투명도 감소, 속도 제한, 방향 반전 거부, 만료, 세션 변경, 보정 무효, 근접 중복 억제, 입력 불변 확인. 대시보드 DOM 모의 실행 통과. 실제 브라우저 시각 검증 및 라이브 송출 시험은 미실시. 운영 반영·서버 재시작 없음.

재현: node scripts/evaluate_minimap_prediction.cjs <출력접두사> <프레임JSON>. 프레임은 time, players, ready를 포함하는 배열이며 기존 guarded dashboard 좌표를 사용한다. 비교 기준 커밋을 로컬에 보유해야 한다.
