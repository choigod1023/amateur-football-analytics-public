# 로컬 학습용 사람 확인

`scripts/run_label_review.py`는 기존 분석 서버와 분리된 로컬 전용 웹 서버를 열고 지정한 MP4의 분석이 끝나면 다시 시작한다. 같은 GPU에서 기존 분석 서버와 동시에 실행하면 GPU 부하가 늘어난다. 오류가 발생하면 자동 재시작하지 않는다. 기본 포트는 `127.0.0.1:18961`이다.

```powershell
$py = '..\football-coach-server\.venv\Scripts\python.exe'
& $py scripts/run_label_review.py --source <원본MP4> --config <분석설정JSON>
```

화면의 **학습용 사람 확인 → 현재 화면 고정**을 누르면 서버가 같은 디코딩 프레임에서 나온 원본 해상도 JPG와 감지 상자·시각을 보존한다. 상자 또는 목록에서 사람을 선택하고 역할, 팀 색상 그룹, 상의 색을 확인해 저장한다. 홈/원정은 정하지 않으며 노랑/빨강 골키퍼를 특정 팀에 자동 연결하지 않는다. 기존 탐지기의 상자를 수정하거나 빠진 사람·공을 추가할 수 없고, 기록은 누락이 있는 부분 주석이다. 이 자료를 자동 학습하거나 분석 결과에 반영하지 않는다.

기존 색상 군집기가 제공하는 A/B는 해당 프레임과 추적 ID에 연결한 미확인 참고값으로 저장한다. A/B와 흰색·파란색, 홈·원정은 자동 대응하지 않는다. 후보가 없는 사람을 목록 앞에 두며 선택한 사람을 원본 프레임에서 확대해 보여준다. 역할과 색상은 사람이 직접 지정하고 자동 후보가 폼의 기본값을 채우지 않는다.

고정 화면과 제출 정답은 `work/human-labels`에만 저장되며 저장소에 포함하지 않는다. 저장 요청은 로컬 접속과 동일 출처 브라우저에서만 허용한다. 화면 고정 시 JPG와 미완료 정보를 보관하므로 영상에 개인정보가 있으면 파일 접근과 보관에 주의한다. 서버가 재시작돼도 최근 고정 화면은 로컬 브라우저에서 복구할 수 있다. 사용자가 같은 화면의 같은 ID를 수정해 다시 저장하면 기존 정답을 덮어쓴다. 임시 ID는 실제 인물 식별을 보장하지 않는다.

기존 송출 18081과 마킹 서버의 동시 분석은 서로 다른 추적 결과를 내므로 ID를 교환할 수 없다. 학습 전에는 원본 경기별로 학습/평가를 분리하고, 탐지에서 빠진 사람과 잘못된 상자를 추가 검토해야 한다. 현장 거리·카메라 기준점과 공 좌표 마킹은 이 기능에 포함하지 않는다.

## AI Hub 학습 자료 질문 화면

`scripts/run_training_questions.py`는 GPU를 사용하지 않고 기존 AI Hub 학습 분할에 있는 9경기 156장의 이미지와 해당 사람 상자를 읽는다. 실제 데이터의 경기/프레임, SHA-256, 학습 분할 정보를 각 답변에 기록하며 `work/human-labels/aihub-train`에만 저장한다. 검증 경기 318과 SoccerTrack 영상은 이 실행기가 허용하지 않는다. 허용 경로와 경기 번호 검사는 데이터 내용의 독립성을 증명하지 않는다. 이 질문 화면은 기존 영상의 스트리밍 화면이 아니라 과거 학습용으로 추출한 **정지 이미지**를 사용한다.

화면을 고정하면 첫 사람부터 확대해 역할을 묻고, 답변을 저장하거나 건너뛰면 다음 사람을 보여준다. `다른 학습 장면`은 다른 학습 이미지로 이동한다. 이 상자는 기존 사람 주석이며 역할·팀 정답이 아니다. 홈/원정은 정하지 않고 색상이나 역할을 모르면 미확인으로 둔다. 팀 색은 경기마다 다르므로 현재 SoccerTrack 영상의 흰색/파란색 대응을 다른 경기 정답으로 적용하지 않는다. 모르는 항목을 건너뛰면 정답 파일을 생성하지 않는다. 검수 여부는 현재 브라우저 세션에서만 기억되며 다른 브라우저에서는 자동 동기화되지 않는다. 기록된 답변을 모델이 자동 학습하지 않으며, 학습 전 프레임·경기 단위 분리와 사람 검수를 다시 해야 한다.

```powershell
..\football-coach-server\.venv\Scripts\python.exe scripts/run_training_questions.py --port 18963
```
