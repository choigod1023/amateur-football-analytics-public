# 야간 영상 조사와 예비 실험

[SoccerTrack v2 공식 프로젝트](https://github.com/AtomScott/SoccerTrack-v2)는 야간 경기장 샘플을 소개하며 코드 MIT, 데이터 CC BY 4.0을 명시한다. [데이터 저장소](https://huggingface.co/datasets/atomscott/soccertrack-v2)의 전체 영상과 프레임 주석은 접근 조건 동의가 필요하다. 상용 이용과 영상별 권리는 원본 조건을 별도로 확인한다. 별도 허가가 필요한 다른 방송 영상은 학습 데이터로 가정하지 않는다.

공식 페이지의 야간 파노라마 이미지 1장(900×376)을 RTX 5070, YOLO11n, confidence 0.35로 시험했다. 해당 웹 이미지의 개별 이용 조건과 원본 영상·주석의 연결 여부는 확인하지 못했다. 입력 크기 640, 1280, 1920에서 사람 후보가 각각 0, 5, 7개였다. 정답 주석이 없어 이 후보의 정확도와 누락률은 알 수 없고 단일 장면의 수치다. 1280에서 나온 후보 5개에 임의로 선택한 청색·백색 기준을 기존 분류기에 적용했을 때 away 1개, unknown 4개였다. 후보 폭은 약 6~11픽셀로 작았다. 이는 영상별 정확도 개선이나 실시간 속도를 증명하지 않는다. 기본 640이 먼 선수에 불리할 수 있어 고해상도·타일 처리 검토가 필요하지만 비용과 정확도 평가 전 기본값을 바꾸지 않았다.

## 후속 평가

사용 권한이 확인된 여러 경기·카메라의 야간 원본 영상을 경기 단위로 개발용과 독립 평가용으로 분리한다. 사람 박스·팀·심판/골키퍼와 가림을 표기하고 탐지 정밀도/재현율, 팀별 혼동표, unknown 비율, 분류된 표본의 정확도를 측정한다. 밝기와 선수 픽셀 크기별로 결과를 나누고, 조명 변화·유사 유니폼·광고판·관중을 별도로 확인한다. 같은 추적 ID의 오류와 바뀜도 기록한다. 단순히 분류 비율을 높이기 위해 불확실한 대상을 팀에 강제하지 않는다.

보정은 기준점 외의 독립 경기장 점에서 미터 단위 오차를 측정하고 화면 안팎, 인원 누락과 발 위치 오차를 기록한다. 야간 고정 카메라와 움직이는 중계 카메라는 별도 평가한다. GPU 처리 FPS 및 VRAM은 동일한 영상 길이·입력 해상도·모델과 GPU 예열 조건에서 측정하고 전송 지연과 구분한다.
