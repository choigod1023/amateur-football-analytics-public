# 팀 분류 자료와 유니폼 표본 시험

## 연구 근거

- [Contrastive Learning for Sports Video](https://arxiv.org/abs/2104.10068)는 선수 영상 임베딩과 군집화로 팀을 나누는 접근을 제시하고 아이스하키에서 평가했다. 촬영 조건이 다른 축구에 같은 정확도가 나온다는 뜻은 아니다. 군집 번호도 자동으로 우리 팀 이름이 되지 않는다.
- [Two Weakly Supervised Approaches for Role Classification of Soccer Players](https://ipcv.github.io/PlayerClassification/)는 선수·역할 분류를 별도 과제로 다룬다. 심판과 골키퍼를 두 팀 중 하나로 강제하지 않도록 역할 주석과 경기 단위 평가가 필요하다.
- [Roboflow sports의 팀 분류 코드](https://github.com/roboflow/sports/blob/main/sports/common/team.py)는 선수 작물의 시각 임베딩을 차원 축소하고 두 군집으로 묶는 예시다. [저장소 코드](https://github.com/roboflow/sports/blob/main/LICENSE)는 MIT이나, 별도 모델 가중치와 학습 이미지의 사용 조건까지 MIT라는 뜻은 아니다. 이 프로젝트는 위 코드를 복사하거나 해당 가중치를 사용하지 않았다.

## 이번 변경과 실험

수동 HSV 입력의 편의성을 높이기 위해 원본 영상에서 사람이 지정한 두 상의 영역의 후보 HSV를 출력한다. 어둡거나 색이 혼합되거나 두 후보가 너무 비슷하면 오류를 낸다. 이것은 팀 분류기 재학습이나 정확도 개선의 증거가 아니다. 출력의 `team_classification_validated`는 항상 false다. 자동 적응이나 실제 영상의 검증 여부 판정도 하지 않는다.

로컬 SoccerTrack v1 한 경기의 첫 프레임에서 흰 상의와 파란 상의를 각각 직접 선택했다. 참고 HSV는 `[0,28,165]`, `[105,226,86]`이며, 비교용 기존 추정치는 `[0,0,150]`, `[110,210,75]`였다. 이어 같은 경기의 다른 시간대 클립 둘에서 각 6프레임, 총 12프레임의 주석 박스 228개를 시험했다. 선수 ID와 팀의 대응은 일부 프레임을 눈으로 본 근사값으로 독립 검수된 정답이 아니다. 탐지기가 아닌 데이터셋의 박스를 입력했다.

보수적 guarded 분류 결과는 기존 추정치에서 일치 23·불일치 0·unknown 205, 표본 후보에서 일치 15·불일치 0·unknown 213이었다. 중앙값 방식은 두 후보 모두 일치 34·불일치 20·unknown 174였다. 표본 방식은 이번 평가에서 보수적 분류의 미분류를 줄이지 못했다. 0 불일치는 적은 수의 예측과 불완전한 정답 때문에 안전성이나 정확도 보증이 아니다. 프레임은 동일 경기의 반복 관측으로 독립 표본이 아니며 주간 단일 경기 결과를 야간이나 아이폰 실전으로 일반화할 수 없다. [프레임별 결과](team-reference-experiment.json)를 보관했다.

자료 출처는 [SoccerTrack 원저자 프로젝트](https://github.com/AtomScott/SoccerTrack)이며, 이번에 로컬에 이미 있던 v1 동영상과 CSV를 썼다. 저장소 코드의 라이선스를 영상·주석의 이용 허락으로 간주하지 않는다. 사용한 v1 영상과 주석 각각의 재배포·학습 조건은 확인하지 못했으므로 프로젝트에 복사하거나 재배포하지 않았다. 위 논문과 외부 코드도 참고 자료이며 별도 가중치 또는 데이터는 사용하지 않았다.

## 다음 검증

촬영 경기별로 날짜·조도·촬영 거리·유니폼 조합을 나누고 선수, 심판, 골키퍼를 사람이 검수한 박스와 팀으로 표시한다. 한 경기에서 색상 표본이나 임계값을 조정했다면 다른 경기 전체를 평가에 남긴다. 팀 혼동행렬과 unknown 비율을 역할·주야간·선수 크기별로 함께 보고한다. 선수 추적 및 탐지 오류까지 평가할 때는 별도로 실제 탐지 출력과 정답을 매칭한다. 외부 사전학습 임베딩을 도입할 경우 코드, 모델 가중치, 학습 데이터의 라이선스를 각각 확인하고 기존 방식과 동일한 독립 경기에서 비교해야 한다. 충분한 근거가 모일 때까지 검증 표시를 자동으로 켜지 않는다.
