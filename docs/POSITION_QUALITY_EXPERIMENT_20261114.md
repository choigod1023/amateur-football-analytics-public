# 위치 투영 품질 실험 (2026-11-14)

이 실험은 발 위치 오차가 경기장 좌표에서 얼마나 증폭되는지 측정한다. 선수 위치의 실제 정답 오차가 감소했다는 실험이 아니다. 기존 운영 코드, 분류 답, 저장 영상은 변경하지 않았다. `app.position_quality`는 어디에서도 자동 호출하지 않는 opt-in 모듈이다.

## 논문에서 얻은 방향

- [PnLCalib](https://arxiv.org/abs/2404.08401): 경기장 3D 기준점으로 초기 카메라 보정을 만들고, 검출한 선을 이용한 비선형 최적화로 개선한다. 현재 점 클릭의 학습내 잔차만 보는 것보다 독립된 선/기준점 검증이 필요하다는 구현 방향을 얻었다. 논문 모델을 이 실험에서 학습하거나 실행한 것은 아니다.
- [TVCalib](https://arxiv.org/abs/2207.11709): 경기장 선분 대응의 재투영 오차로 카메라 자세와 초점 거리를 추정한다. 임의 호모그래피 하나의 낮은 잔차가 카메라 및 선수 좌표 정확도까지 보장하지 않는다. 후속 작업은 선분 검출과 카메라 모델 검증이다.

논문 코드를 복사하거나 가중치를 내려받지 않았다. 아래 수학 진단은 기존 호모그래피에 대해 독립적으로 작성했다.

## 구현과 검증 방법

기존 `pitch_map.fit`을 그대로 이용하고, `shift` 및 `bg`를 합성한 픽셀→경기장 투영행렬의 해석적 Jacobian을 계산한다. 입력 발점은 상자 아래 중앙이다. 발점이 x/y 각각 ±3px 움직이는 사각형의 네 꼭짓점을 실제 투영하여 중심에서 가장 먼 거리를 구한다. 분모가 전체 사각형에서 양수이면 투영된 사각형은 볼록하므로 꼭짓점 최대 거리가 이 **발점 이동 시나리오만의** 상한이다. 카메라 오차·보정 오차·골격 오차·경기장 치수 오차는 포함하지 않는다. 95% 신뢰구간이 아니다.

분모가 0을 지나거나 퇴화된 행렬이면 거절한다. 선 밖 좌표는 그대로 보존하여 `outside`, 중심은 안쪽이지만 발점 시나리오가 선 밖까지 닿으면 `boundary_uncertain`으로 표시한다. 팀/역할은 입력하지 않으므로 unknown 팀도 위치 품질을 독립적으로 평가한다. `tactical_foot_gate`는 임의의 실험 기준 1m와 경기장 내부 조건만 검사하며, 통과해도 전술 정확도가 입증되지 않는다.

잘못된 box/bg/H 형식은 명시적으로 invalid를 반환한다. `position_quality`는 호출자가 넘긴 투영행렬의 기하만 진단하며 MAX_RMS를 재검사하지 않으므로 `calibration_fit_gate_checked=false`를 반환한다. 평가 스크립트는 먼저 기존 `fit()`의 MAX_RMS 검사를 통과시킨다. 이 검사와 1m 발점 기준은 서로 다른 검사다. shift/bg 합성 결과를 기존 `feet_to_metres`와 대조하는 회귀 테스트를 포함해 12개 테스트가 통과했다.

실행은 프로젝트 가상환경에서 다음과 같다.

```powershell
python -m pytest tests/test_position_quality.py -q
python scripts/evaluate_position_quality.py --project-root ../.. --output ../../work/paper-improvements-20261114/position
```

## 실제 녹화 결과

run-73의 60초, 300프레임, 원시 사람 추적 관측 9,153개 전체를 평가했다. 관중도 포함되며, 운영상 유효 선수의 정확도나 비율로 읽으면 안 된다. 1920×1080, cam3, shift=(-1.8,6.8), bg=(1.003087,-0.001614,-7.41,5.61)을 재사용했다. 영상 전체에서 해당 변환이 맞는지는 별도 검증되지 않았다.

| 측정 | 값 |
|---|---:|
| ±3px 양축 발점 시나리오 반경 중앙값 | 1.653m |
| 90 / 95백분위 | 3.943 / 4.495m |
| 최대 | 12.798m |
| 안쪽 / 경계 불확실 / 중심이 밖 | 5,762 / 225 / 3,166 |
| 1m 발점 기준 또는 안쪽 조건 미충족 | 8,367 |

관중 영향을 줄이기 위해 로그에서 팀별 `raw_positions`에 들어간 관측만 따로 집계했다. identity event의 raw ID→segment ID를 적용해 **5,358개 중 5,358개를 원시 상자와 연결**했다. 이 집합의 반경 중앙값은 1.728m, 95백분위는 3.125m, 최대는 4.479m다. 안쪽 5,261개, 경계 불확실 58개, 밖 39개이며 4,582개가 1m 발점 기준 또는 내부 조건을 충족하지 못했다. 이는 기존 팀 분류/위치 필터 전 후보 집합이므로 전부 진짜 선수라고 검증된 것은 아니다. 코칭을 다시 실행해 알림 정답률이 개선된 실험도 아니다. 단정형 거리 코칭에 필요한 입력 품질 검증이 부족하다는 정량적 진단이다.

89×60m는 추정 경기장 치수다. 11개 클릭점의 학습내 RMS는 0.961m지만, 하나씩 제외한 점의 재투영 최대 오차는 4.115m(왼쪽 먼 코너)다. 이는 클릭과 보정의 일관성 진단이며 측량된 실제 선수 위치 정답이 아니다. 현재 입력으로 정밀한 거리 기반 압박·침투 판정을 단정할 근거가 부족하다.

| 확인 요청한 raw ID | 투영 위치 x,y (m) | 발점 반경 | 경계 |
|---|---|---:|---|
| 430 | 26.579, -6.050 | 2.029m | 안쪽 |
| 259 | 39.522, 0.633 | 1.833m | 안쪽 |
| 909 | 46.329, -27.123 | 4.085m | 밖 |
| 998 | 13.385, 9.137 | 1.012m | 안쪽 |
| 748 | 12.923, 9.033 | 1.012m | 안쪽 |

909는 길이의 절반 44.5m를 초과한다. 기존 ±2m 여유 구간에는 들어가지만 이 진단에서는 선 밖임을 명시한다. 사용자의 관중 답과 일치하는 기하학적 단서지만, 기하학만으로 관중을 확정하지 않는다. 998과748의 중심이 가깝다는 이유로 같은 사람으로 병합하지 않는다. 큰 상자의 발점 자체가 틀릴 수 있고, 발점 ±3px 가정이 그 오류까지 설명하지 못한다.

## 다음 검증

1. 선수의 실제 접지점을 다른 프레임과 함께 확인해 픽셀 오차 분포를 얻고, ±3px 가정을 검증한다.
2. 보정에 쓰지 않은 선/기준점과 실제 경기장 치수를 확보한다. 선+점 기반 카메라 최적화 후보는 기존 보정과 동일한 독립 기준점으로 비교한다.
3. 코칭 거리 임계값에 대해 발점과 보정 오차를 각각 전달한다. 임계값을 가로지르는 경우 단정형 코칭을 보류한다.
4. 운영 적용 전 유효 선수 대상의 별도 집계와 시간별 카메라 드리프트 검증이 필요하다. 이번 결과로 운영을 자동 변경하지 않는다.
