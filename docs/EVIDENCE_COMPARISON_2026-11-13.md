# 추적·코칭 근거 개선 비교

## 범위와 보존

기존 운영 자료는 읽기만 했다.
`work/evidence-policy-eval-20261113`에 JSON/JSONL 1,167개를 복사하고 SHA-256 manifest를 저장했다. 복사 후 비교 실행을 마쳤을 때 원본 해시는 모두 동일했다. 영상·사진·모델은 이 스냅샷의 복사 대상이 아니다. 평가 출력과 개인정보가 있는 스냅샷은 Git에 넣지 않는다.

## 구현

- 경기장 좌표 변환은 보간·예측 행을 기본 제외한다. `include_estimates=True`는 이전 동작 비교용이다. 별도 evidence 카운터를 제공한다.
- 보고서가 보정 파일의 경기장 크기를 사용한다. 기존 후반 설정 89×60m를 89×62m로 덮어쓰던 동작을 제거했다. 실제 측량 정확도를 새로 확보한 것은 아니다.
- 선수 배정 및 연결의 새 사람 확인은 별도 provenance에 기록한다. 기존 답은 삭제·변경하지 않는다. 과거 출처 불명은 legacy_unknown, 자동 번호 판독은 auto_unconfirmed이며 기존 화면의 이름은 유지한다. 확정 선수 카드는 명시적으로 확인된 답만 사용한다.
- 추적 연결에 상호 최우선·차순위 차이 검사, 묶음 전체 시간 충돌 검사, 전이적인 ‘다른 사람’ 제약을 추가했다. `track_from_cache.py --guarded-stitch`로 보수적 후보 검사를 선택할 수 있다. 재추적으로 번호가 바뀐 자료에 과거 번호 제약을 그대로 적용하면 안 된다.
- 코칭 출력에 공 미관측과 선수 위치 기반이라는 근거를 추가했다. 패스 출발점은 공 소유자가 아니라 가장 앞선 선수라는 출처를 반환한다.

알림 9개 감소는 순감소다. 일부 알림 종류는 늘었으며 모든 차이가 단순 삭제는 아니다. 이는 보간을 제외한 민감도 비교이고 오경보 9개 제거를 의미하지 않는다. 같은 보정으로 비교한 후 저장 보정을 별도 적용했으며 알림 수는 같았다. 전반 공격 방향은 아직 확인되지 않았다.

전체 부정 답을 연결 금지에 사용한 2→0은 사용자 답 준수 결과다. 정확도 평가로 제시하지 않는다.

### 숨긴 답 평가

‘다른 사람’ 쌍을 SHA-256 정렬 후 교대로 제약/평가용으로 고정 분리했다. 전반 10/9쌍, 후반 3/3쌍이다. 같은 선수나 조각이 양쪽에 있을 수 있어 경기 단위 독립 평가는 아니다.

| 평가 항목 | 이전 | 보수적 연결 + 일부 제약 |
|---|---:|---:|
| 전반 숨긴 부정 답 9쌍 오연결 | 1 | 1 |
| 후반 숨긴 부정 답 3쌍 오연결 | 0 | 0 |
| 전반 같은 사람 5쌍 연결 | 1 | 1 |
| 후반 같은 사람 9쌍 연결 | 1 | 1 |

독립적으로 숨긴 답에서 정확도 향상은 확인하지 못했다. 이미 연결된 저장 결과에 추가 연결한 검사이며, 앞선 단계의 ID 전환과 전체 HOTA/IDF1은 측정하지 않는다. 현 모델 가중치를 재학습하거나 새 모델로 교체하지 않았다.

## 선수 카드 주의

현재 자료에는 새 provenance가 없으므로 명시적으로 확정된 조각은 0개다. 전반 자동 미확인 7개, 출처 불명 7개와 미확인 연결 2개, 후반 자동 미확인 7개가 확인됐다. 기존 답이 사라진 것이 아니다. 과거 사람 확인 내역을 복원할 수 있는 기록을 먼저 찾아야 하며, 사람에게 모든 답을 다시 입력하라고 요구하지 않는다. 운영 카드 폴더를 새 결과로 덮어쓰지 않았다.

## 다음 검증과 운영 상태

1. 기존 사람 확인 기록의 출처 복구를 우선하고, 복구할 수 없는 애매한 조각만 확인받는다.
2. 새로운 장면의 사람 추적 정답을 고정해 ID 전환·미연결·오연결을 평가한다. 이번 숨긴 답을 추가로 조정에 사용하면 새 평가셋이 필요하다.
3. 변경 전후 알림의 합집합을 장면별로 평가해야 코칭 정확도와 유용성 향상을 계산할 수 있다. 현재 확인한 alerts/labels에는 평가 자료가 없다.
4. 별도 기준점을 사용한 보정 오차와 전반 공격 방향을 확인한다. 그 전에는 미터값과 방향 기반 코칭은 검증되지 않았다.

서버 재시작·운영 배포·기존 추적 및 카드 교체는 수행하지 않았다. 기능 구현, 오프라인 비교, 실경기 정확도, 배포 상태는 서로 다르다.
