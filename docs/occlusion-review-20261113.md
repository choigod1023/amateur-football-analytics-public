# 완전 미탐·가림 뒤 재등장 검증

## 구현

- 직전 관측 상자만으로 국소 검색 영역을 정하는 `app/local_redetect.py`와 실제 영상 비교 도구 `scripts/probe_missing_players.py`를 추가했다. ROI는 160~384픽셀, 추론 해상도768이다. 이후 프레임 정보는 검출기에 전달하지 않는다. 후보를 발견해도 신원을 확정하거나 추적기에 자동 병합하지 않는다.
- `/train`에서 `/train/reappearance`로 들어가 필요한 재등장 질문만 볼 수 있다. API `scope=occlusion-reappearance`가 질문·완료 수를 분리한다. 기존 검토 화면과 질문·답은 그대로 남는다.
- 원본 영상 SHA256과 질문 fingerprint가 일치하는 인간 답만 연결 승인·연결 금지로 읽는다. `GET /api/v1/reappearance/decisions?source_sha256=...`로 조회한다. same도 해당 경계에만 적용되며 시간상 겹치는 조각의 전체 병합을 허용하지 않는다. 답 저장은 모델 재학습이나 라이브 ID 변경을 자동 실행하지 않는다.
- 게시 도구는 기존 질문 객체를 수정하지 않고 새 질문만 덧붙인다. 기존 답이 있거나 동일 case_key이면 다시 질문하지 않는다. 미디어를 먼저 생성하고 원본 queue가 바뀌지 않았는지 확인한 뒤 교체한다.

## 미탐 비교

기존 녹화1950~2010초에서 양끝에는 같은 ID가 있지만 중간에는 관측이 없는6장면을 골랐다. 현재 프레임과 예측 영역의 겹침은 검색 힌트이며 사람이 그린 정답 상자가 아니다.

| 모델·탐지 방식 | 힌트 IoU ≥0.5 후보 / 6 |
|---|---:|
| 운영 yolo11n, 기존 타일 |0|
| 운영 yolo11n, 국소 확대 |0|
| 기존 학습 모델 ft_n2, 기존 타일 |4|
| 기존 학습 모델 ft_n2, 국소 확대 |2|

국소 확대 자체가 만능 해결책은 아니었다. ft_n2는 기존 자료로 학습한 모델이고 이6장면의 학습 중복 여부·독립 정답은 확인하지 못했다. 따라서4/6을 정확도나 검증된 복구율이라고 쓰면 안 된다. 이 실험으로 운영 모델은 교체하지 않았다. 국소 호출은 약14~21ms였으며 모델 로딩·전체 프레임 처리·전체 서비스 부하는 별도다.

## 재연결과 인간 확인 최소화

시간이 겹치지 않고 팀 관측이 있으며 근접한 재등장 후보11쌍을 실제 앞뒤 프레임으로 검토했다.32→276,15→427,31→484,22→417은 상의/인물이 달라 보여 자동 병합에서 제외했다.29→431은 근거리 연속성이 잘 보여 질문 우선도를 낮췄지만 이를 독립적인 정답으로 저장하지 않았다.

최종 질문은 원거리의 모호한3쌍이다.

| 질문 | 재생 상대 시각 | 후보 ID |
|---|---|---|
|d0108|47.8→50.2초|845→1004|
|d0109|55.8→57.6초|16→1055|
|d0110|33.8→36.6초|638→824|

각 질문에 사라지기2초 전부터 재등장2초 후까지의 실제 영상(끝부분은 원본60초 길이 제한), 전체 화면과 같은 시각의 확대 영상, 양끝 관측 상자를 표시한6배 확대 사진을 제공한다. 숨겨진 동안 위치를 그리지 않는다. 같은 선수·다른 선수·판단 어려움 중 선택한다. 판단 어려움을 강제로 정답으로 변환하지 않는다.

기존d0105 same 답은 다른 경계(원본1982.4초)이므로 반복 질문하지 않았다. 게시 중 기존 JSON1,186개는 변경되지 않았으며 queue만 새 항목을 추가했다. 기존 항목의 객체 내용과 답 fingerprint는 유지했다.

## 검증·한계

회귀 테스트는 범위별 질문 필터, 답 저장 후 대기 제외, 다른 영상 hash/오래된 답 차단, negative 답 유지, 국소 ROI 경계, 공개 훈련 경로를 다룬다. 원본 영상·분류 답·운영 분석 프로세스는 교체하지 않았다. 웹 UI 변경을 위해 검토 웹 서버만 새 커밋으로 재시작한다.

실험 원본과 감사 파일: `work/occlusion-review-20261113/`. 새 모델 전체 영상 오탐/ID 전환 검증은 아직 없다. 현재 질문에 답하면 다음 검증에서 해당 경계만 인간 근거로 적용할 수 있다. 가려진 선수를22명 가정으로 임의 생성하지 않았다.
