# 우리 야간 경기의 평가 대기 구간 고정

2026-11-15. 이미 학습에 쓴 60초 영상을 독립 평가로 다시 이름 붙이지 않고, 현재 확인 가능한 예시 시각과 떨어진 구간을 새로 잘라 평가 대기 자료로 준비했다. **아직 정답이 없으므로 정확도와 운영 승격 여부를 계산하지 않는다.**

## 보존한 기존 답

`differences/queue.json`과 사람 답의 ID, source=human, 현재 fingerprint, 영상 SHA256을 대조했다. 현재 60초 replay의 경계·source hash를 확인할 수 있는 d0108~d0115 8개(같음 7개, 다름 1개)를 재사용했다. 8개 모두 과거 identity-retraining 학습 자료에 이미 포함돼 있으므로 historical training으로만 기록한다.

같은 raw track을 공유하거나 검토 문맥이 인접한 답을 묶어 분할 누출을 막는다. 이번 자료의 그룹은 `[d0109]`, `[d0108,d0110,d0111,d0112,d0113]`, `[d0114,d0115]`이다. 이것이 모든 실제 인물의 정체성을 해결했다는 뜻은 아니다. d0105~d0107은 이 source hash와 경계 필드가 없어 이 60초 영상의 정답으로 강제 이식하지 않았다. 원래 답은 그대로 남아 있다.

## 새 구간 선정 근거

원본 `work/own-match-merged-20261111/match_from_17min.mp4`의 시각을 사용했다. 다음 자료를 읽고 각 구간 양옆 60초를 제외했다.

- 역할 검토 JSON의 모든 source_provenance.clip_time_sec. 기존 train뿐 아니라 eval·unassigned도 보수적으로 포함.
- 공 index의 54개 후보 클립 전체. 검수 여부와 관계없이 포함.
- 차이 검토 queue의 시각과 앞뒤 2초.
- 사람 이벤트 답이 저장된 후보의 시작~끝.
- 기존 개발 replay 1950~2010초 전체.

카메라별 남은 시간은 cam1의 1130~1140초(10초), cam2의 1500~1645초, cam3는 없음이었다. 따라서 **cam2 1560~1585초(26:00~26:25)** 25초를 고정했다. cam3에서 시간 버퍼를 줄여 평가 구간을 억지로 만들지 않았다.

이 구간은 현재 감사한 예시 인덱스와 시간적으로 분리돼 있다. 하지만 같은 경기의 같은 선수이며 원본 전체에 과거 자동 스캔·이벤트 후보 생성이 수행됐다. 모든 과거 모델의 학습 이력을 완전히 확인하지 못했으므로 **완전히 미사용한 영상, 독립 경기, 신원 독립 시험으로 부르지 않는다.** 지금부터 이 구간과 앞으로 받을 답을 평가용으로 고정하고 학습에 다시 넣지 않는 것이 목적이다.

## 실제 산출물

프로젝트 루트 `work/own-match-benchmark-20261115/benchmark/`:

- `evaluation-pending-cam2-1560-1585.mp4`: 25초, 1920×1080, 30fps, 750프레임. 마지막 프레임도 디코딩 확인.
- `pending-1565.jpg`, `pending-1572.jpg`, `pending-1580.jpg`: 원본 시각/프레임 번호를 기록한 실제 이미지 3개. 중간 이미지를 직접 확인했으며 야간 경기장, 선수와 전경 관중이 보인다.
- `manifest.json`: 원본/클립/이미지 SHA256, 사람 답 출처, 역사적 학습 그룹, 평가 대기 상태, 미확인 항목.
- `exclusion-audit.json`: 제외한 모든 시각, 60초 버퍼 및 카메라별 남은 구간.
- `command.json`: 실제 FFmpeg 실행 인자.

영상 추출은 원본을 읽고 새 파일을 만들었다. 사람 답 JSON 1,204개의 SHA256이 실행 전후 모두 같았다. 기존 queue에 새 질문을 게시하거나 기존 모델·운영 설정을 바꾸지 않았다.

## 아직 필요한 확인

평가 manifest의 `ground_truth`, `metrics`는 null이고 `promotion_allowed`는 false다. 세 장의 사진만으로 25초 전체 추적 정답이 생기지는 않는다.

1. 보이는 사람의 상자와 역할을 확인하고, 모델이 놓친 사람과 관중을 구분해야 한다. 불명확한 사람을 임의로 선수로 확정하지 않는다.
2. ID 변경을 평가하려면 앞뒤 영상에서 동일인 연결을 확인해야 한다. 기존 팀 답은 개인 신원 정답을 대신하지 않는다.
3. cam2는 기존 cam3와 구도가 다르므로 cam3 보정을 적용하면 안 된다. 이번 구간의 목적은 먼저 사람 탐지·역할 평가이며, 미니맵 보정과 발점 정답은 별도 대기 상태다.
4. 독립 경기 일반화 검증은 추후 별도 촬영 자료가 필요하다. 이번 평가 대기 구간은 그 검증을 대신하지 않는다.
