## 논문에서 가져온 설계와 구현 범위

[BPBreID 논문](https://arxiv.org/abs/2211.03679)과 [공식 코드 설명](https://github.com/VlSomers/bpbreid)은 신체 부분별 표현과 서로 보이는 부분을 비교하는 방법을 제시합니다. 기존 상체 색상 집계는 공간 배열을 버리므로 신체 전체의 배열을 보존하는 실험을 추가했습니다. 다만 이번 구현은 **BPBreID 재현이나 사전학습 CNN이 아닙니다**. 기존 환경에 캐시된 torchvision 가중치가 없어 NumPy로 구현한 32개 셀의 9방향 기울기 히스토그램과 4×8 공간 색상 특징을 썼습니다. 외부 코드·가중치·데이터를 다운로드하지 않았습니다. 라이선스가 새로 필요한 외부 모델은 도입하지 않았습니다.

주변 맥락은 별도의 3배 크롭에서 대상 인물을 검게 마스킹한 8×8 RGB입니다. 몸 색상과 배경 색상이 한 통계에 섞이지 않습니다. 이것은 논문이 입증한 축구 역할 분류 방법이 아니라 이번에 검증한 가설입니다. 확대는 원본에 없던 디테일을 만들지 않습니다.

[SoccerNet-GSR](https://arxiv.org/abs/2404.11335)은 위치·역할·팀·신원·카메라 보정을 함께 다루며 GS-HOTA를 제시합니다. 여기서는 역할/팀만 측정했으므로 미니맵·재연결·코칭 개선으로 확대 해석하지 않습니다.

## 후속: 실제 사전학습 CNN 동결 실험

HOG형 실험과 별도로 **MobileNetV3-small ImageNet1K V1**의 동결된 576차원 특징에 기존 24차원을 합친 후보 하나를 평가했습니다. torch 2.14.1+cu130 / torchvision 0.29.1+cu130 환경에서 CPU 2 threads로 실행했습니다. 본체 가중치를 갱신하지 않고 기존 hidden24/500epochs/3seeds 분류기만 학습했습니다. 사람 전체가 잘리지 않도록 정사각형 여백을 추가한 뒤 공식 전처리를 적용했습니다. 이 모델은 축구 선수 재식별에 특화된 BPBreID가 아닙니다.

공식 [모델 문서](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.mobilenet_v3_small.html)의 9.8MB 모델을 프로젝트 `work/paper-improvements-20261114/visual/torch-cache`에만 받았습니다. 실제 10,306,551 bytes, SHA256 `047dcff4addef86ea5bc2eff13c9614dc11f47ab1160d0a71a25e7db994f4e1f`입니다. [torchvision 코드 라이선스](https://github.com/pytorch/vision/blob/main/LICENSE)는 BSD 3-Clause이며, [공식 가중치 안내](https://docs.pytorch.org/vision/stable/models.html)는 학습 데이터에서 유래한 별도 조건이 있을 수 있다고 명시합니다. 코드 라이선스를 가중치·ImageNet 데이터 라이선스 전체로 간주하지 않습니다. ImageNet 데이터셋을 받지 않았으며 가중치는 로컬 연구 실험에만 사용하고 배포·재배포하지 않았습니다.

결과는 **123/136 (90.44%)**로 기존 126/136보다 나빴습니다. 관중 36/39, 심판 10/11은 기존과 같지만 A팀 37/43, B팀 40/43으로 팀 구분에서 후퇴했습니다. 학습 740/740 및 새 답 5/5를 맞혔고 ID909 관중 점수 0.994였으나 이것은 역시 학습 성과입니다. 분류기 정규화·학습에서 평가 136개 및 동일 해시 이미지를 제외했고 모든 답·사용이미지가 보존됐습니다.

876개 이미지 준비+동결 특징 추출 4.01초, 분류기 학습+전체 추론 1.85초였습니다. 다운로드·초기 모델 로딩 시간과 실제 라이브 전체 경로는 포함하지 않습니다. 전체 인물 유지/RGB 순서 및 잘못된 상자 방어 테스트 2개 통과했습니다.

`evaluate_frozen_visual.py`와 `visual/frozen1/metrics.json`, `manifest.json`에 재현 정보가 있습니다. 기존 실행 명령의 스크립트를 `scripts/evaluate_frozen_visual.py`로 바꾸고 새 출력 폴더를 지정하면 됩니다. 후보는 운영에 적용하지 않습니다.

**평가 한계:** 같은 136개 답을 여러 후보에서 이미 확인했으므로, 이제 이 세트는 모델 선택에 노출된 개발 검증 세트입니다. 결과가 좋아져도 독립 최종 테스트라고 부를 수 없습니다. 이번 후보 하나에서 개선이 없었다는 사실을 보고하며, 다른 모델을 계속 바꾸어 이 136개 최고점만 찾지 않았습니다. 사전학습 일반 이미지 표현만 추가한다고 야간 저해상도 팀 분류가 자동 해결되지는 않았습니다.
