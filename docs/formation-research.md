# 관측된 선수 분포의 변화

[위치 자료 기반 공간 지표 검토 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC8008301/)은 폭·길이와 그 변화가 공간 사용을 기술하는 방식임을 설명한다. 이는 화면 밖 선수나 공·상대·경기 맥락이 빠진 단일 화면의 관측만으로 전술 성공, 실수, 의도를 판단할 수 있다는 뜻은 아니다. [SoccerNet 행동 시점 인식](https://www.soccer-net.org/tasks/action-spotting)은 특정 사건과 시점을 찾는 별도 작업으로, 여기서 구현한 간격 변화 규칙이 골·패스·결정적 장면 판정이 아님을 구분한다.

`formation_observation: true`는 같은 추적 ID로 팀이 확인된 화면 내 선수 3명 이상을 연속 관측할 때, 1~3초 구간에 폭 또는 길이가 5m 이상 달라진 경우 `formation_changes`와 한국어 관찰·해석·제안·한계를 만든다. 새로 나타나거나 사라지는 ID는 비교에서 빼고, 구간 전체에서 계속 보인 공통 선수로 두 시점의 범위를 각각 계산한다. 사라졌다가 다시 나타난 ID는 해당 비교에 다시 넣지 않는다. 5m는 알고리즘 실험용 임계값으로 전술적으로 좋고 나쁨을 뜻하지 않는다. 공통 선수가 3명 미만인 경우, 중복 ID·위치 누락·시간 역행·장시간 공백·미검증 설정 시 이력을 비우고 추론을 보류한다. 일정 프레임레이트를 사용자가 확인한 로컬 파일, 사용자 검증 표시된 팀 분류, 실제 해상도와 일치하는 검증 보정이 모두 필요하다. 선택형 카메라 가드가 켜진 경우 안정 상태도 필요하다. SRT에는 정확한 영상 시간 축이 없어 비활성이다.

[SkillCorner 공개 추적 데이터](https://github.com/SkillCorner/opendata)의 한 방송 경기 약 70초를 1초 간격으로 비교했을 때, 구간 내 공통 ID를 비교할 수 있는 시점은 14개에서 32개로, 임계값을 넘는 관찰은 0개에서 1개로 늘었다. 제공자의 영상 기반 추정 좌표를 사용한 함수 실험이며, 우리 영상 탐지 결과나 전술 판단의 정확도 검증은 아니다.

동일 ID라도 실제 사람의 동일성을 보증하지 않고, 미탐·화면 밖 선수·관중·심판·가림·카메라 오차는 남는다. 추가된 결과는 한 분석 시점의 관측 후보이고 자동으로 영상 클립을 저장하거나 사건의 중요도를 판단하지 않는다. 단위 테스트는 합성 좌표로 단위 변환, 변화 감지, ID 변경·시간 역행·위치 누락 및 검증 상태를 확인했다. 실제 경기 영상에서 팀 분류와 위치의 정답, 카메라 고정 여부를 검증한 뒤 평가해야 한다. 단위 테스트는 현장 정확도의 증거가 아니다.
