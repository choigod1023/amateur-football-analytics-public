# 고정 광각 영상 실험

로컬 SoccerTrack 영상 네 구간은 같은 경기·카메라의 각 30초, 6500×1000, 25fps 파노라마다. 각 구간의 1초와 25초 화면에서 배경 특징점의 중앙 이동은 축소 이미지 기준 0픽셀이었다. 일부 시점의 확인이며 모든 시간에 카메라가 고정됐다는 증명은 아니다. 동일 경기의 CSV 주석이 있다. 영상·주석의 이용 조건은 코드 라이선스와 별도로 확인해야 하므로 외부에 재배포하지 않았다. 출처: https://github.com/keisuke198619/SoccerTrack

선수 상자 높이의 중앙값은 원본 기준 구간별 30.6~59.9픽셀이었다. 가로 1280픽셀로 전체 프레임을 줄이면 약 6~12픽셀이 되어 작은 선수가 탐지에서 사라질 수 있다. 원본 파노라마를 겹치는 타일로 나누어 탐지하고 하나의 추적기로 합치는 기존 선택 기능을 로컬 재생목록에 적용했다. 이것은 전체 선수 탐지 정확도에 대한 보증이 아니다.

CPU에서 YOLO11n을 2에폭 학습했다. 동일 경기의 첫 30초 중 10프레임을 다섯 타일로 나눈 것을 학습에 사용하고, 같은 경기의 120~150초에서 6프레임을 다섯 타일로 나누어 평가했다. mAP50은 0.188→0.382, 재현율은 0.318→0.477이었다. 한 경기의 상관된 소수 프레임으로 비교한 개발 결과이며 경기 단위 독립 시험이 아니다.

다른 AI Hub 781경기 6프레임 사람 상자 127개에 동일 평가 조건을 적용하면 mAP50은 기본 0.795→학습 후 0.316, 재현율은 0.740→0.512로 악화했다. 별도 AI Hub 310경기의 10프레임을 훈련에 섞은 모델도 781경기에서 mAP50 0.303이었다. 781경기는 이전 연구에서 사용됐고 표본이 작으며 원본 분류 주석에도 오류 가능성이 있다. 이 수치는 팀·심판·보정·코칭 성능이 아니다. 두 새 가중치는 배포하지 않았다.

다음에는 여러 경기·서로 다른 카메라·조명에서 경기 단위로 학습/개발/최종 테스트를 나누고, 작은 선수·심판·골키퍼 주석의 품질을 확인한다. 보정은 별도의 실제 필드 기준점과 선수 발 위치의 미터 오차, 팀은 역할·팀 정답과 오분류/보류를 측정해야 한다. 실험 산출과 접근 제한 데이터는 이 PC의 `work/wide-cpu-experiment`에만 둔다.
