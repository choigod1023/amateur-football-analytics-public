# 미연결 원인과 장면 검토

## 원본 보존

기존 1,167개 JSON/JSONL의 SHA-256을 배포 후 다시 비교했고 변경 0개였다. 새 페이지 자료는 `differences`에만 추가했다. 기존 assign/links/roster와 추적 파일은 바꾸지 않았다. 서버 시작 전 저장소 6,787개 파일을 별도 백업했다.

## 추적 원인 및 개선

같은 사람으로 답한 14쌍 중 9쌍은 동시 관측이 겹쳤다. 일부는 서로 먼 위치에서 동시에 관측돼 전체 조각을 병합할 수 없다. 조각 내부의 ID 전환, 과거 재추적 라벨 이전, 일부 시점만 뜻한 답 중 무엇이 원인인지는 미확정이다.

후반 496→2841은 마지막 두 상자가 발부분만 잡아 속도 예측이 빗나갔다. 새 endpoint_evidence 옵션은 연결 계산에서 보간과 최대 두 개의 급격히 축소된 끝 상자를 제외한다. 원래 관측 행을 삭제하지 않는다. 동시 실제 관측 상자가 떨어져 있는 경우는 backfill로 간주해 연결하지 않는다. `--guarded-stitch`에 연결했으며 기본 옵션과 운영 추적 결과는 유지한다.

라벨을 강제 연결/금지 조건으로 사용하지 않은 회고 개발 평가:

| 항목 | 기존 | 개선 |
|---|---:|---:|
| 기존 같은 사람 답과 연결 일치 | 2/14 | 3/14 |
| 기존 다른 사람 답을 어긴 연결 | 2/25 | 1/25 |

이 수치는 전체 선수 추적 정확도 또는 새 경기 성능이 아니다. 원인을 찾을 때 사용한 개발 자료이며 일부 정답의 적용 시간 범위에도 충돌이 있다. 새로운 독립 장면과 ID 전환 정답이 필요하다.

## 코칭

LiveAnalyzer가 다음 초의 첫 관측을 이전 초의 배치로 기록하던 오류를 수정했다. 이전 초의 마지막 실제 표본을 보관해 계산하며, 급격한 위치 변경을 시간상 앞당기지 않는 회귀 시험을 추가했다.

직전 관측 전용 정책 알림 88개(47+41)가 시간 수정 후 87개(46+41)다. 최초 보간 포함 버전은 97개였다. 이는 알림 발생의 차이이며 오경보 감소나 코칭 유용성 개선률이 아니다.

후반은 방향이 확인됐으므로 후반에서만 바뀐 알림을 고른다. 같은 종류의 알림을 3초 허용 범위에서 일대일 대응시켜 단순 시각 이동을 별도 사건으로 세는 것을 줄였다. 최초 버전과 최신 버전 사이 후반 미대응 알림은 이전 21개, 변경 18개다. 20초 이상 간격을 둔 6개 시점의 16초 원본 영상으로 검토 대기열을 만들었다. 새로 맞춘 장면에는 알림 전후 제목과 시각을 함께 제공한다. 실제 알림 정답은 사람이 확인하기 전까지 미정이다.

## 질문 최소화

두 추적 충돌 시점은 확대 사진에서 동시 별개 인물임을 확인해 반복 질문에서 제외했다. 이 관찰은 `automatic_conflict_review.json`에 자동 검토로 기록했고 사람 정답으로 저장하지 않았다. 나머지 미연결 쌍의 기존 답도 재질문하지 않는다. 현재 페이지에는 코칭 비교 6개만 있다.

페이지 `/review-differences`, API `/api/v1/differences`. 답은 `differences/answers`에 별도로 저장한다. 기존 답 덮어쓰기 거부, 동일 요청 재시도 허용, 답한 장면 기본 숨김, 자동 만료 없음. 영상 MP4 Range 응답을 지원한다. 답 저장만으로 모델이 자동 학습되지는 않는다.
