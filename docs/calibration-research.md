# 경기장 보정과 카메라 이동 연구

## 근거와 적용 범위

- [SoccerNet calibration 공식 저장소](https://github.com/SoccerNet/sn-calibration)는 경기장 선과 카메라 모델을 사용하여 투영을 평가한다. 보정에 사용하지 않은 선이나 기준점을 검증에 쓰는 것이 중요하다. 데이터 조건, 카메라 모델과 렌즈 왜곡에 따라 오차가 달라진다.
- [PnLCalib 공식 저장소](https://github.com/mguti97/PnLCalib)는 점과 선을 함께 사용하고 렌즈 왜곡을 다루는 방법을 제시한다. 이 프로젝트에 해당 학습 모델이나 코드를 도입한 것은 아니다. 정확한 경기장 선·점 주석과 카메라 조건을 갖춘 자료가 필요하다.
- 이번 변경은 기존 수동 평면 호모그래피를 유지하고 [OpenCV ORB](https://docs.opencv.org/4.x/d1/d89/tutorial_py_orb.html)와 [OpenCV 기하 추정](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html) 기능을 사용한 독립적인 보조 감시다. 평면 영상 좌표에서 경기장 좌표로 변환하는 작업은 선수의 발이 경기장 평면에 있다는 근사에 의존한다.

기준 프레임의 보정 영역에서 특징점을 추출하고 현재 영상과 매칭해 RANSAC 유사변환의 인라이어를 확인한다. 인라이어가 충분할 때 특징점 변위 90백분위가 축소 영상 너비의 0.3%를 넘으면 보류한다. 임계값은 현장 데이터로 최적화한 수치가 아니다. `active`는 카메라 불변이나 위치의 정확성을 증명하지 않는다. 움직이는 선수의 특징점이 지배적이면 오탐 또는 미탐할 수 있고 화면 내부의 부분 변형, 줌, 원근, 렌즈 왜곡, 흐림과 조도 변화도 완벽하게 판별하지 못한다. 구도가 달라지면 재보정해야 한다.

## 확인 결과와 평가 계획

합성 질감 영상에서는 동일 영상, 수평 이동, 무특징 영상과 해상도 불일치에 대한 동작을 테스트했다. 기존 ISSIA 영상 한 개에서 0, 10, 50, 100, 250, 500, 1000, 2000번 프레임을 첫 프레임과 비교한 8회는 모두 안정으로 나왔고, 같은 8장에 인위적인 수평 12픽셀 이동을 추가하면 모두 이동으로 나왔다. CPU 검사 시간은 표본 8회에서 약 4.86~11.25ms였으며 나머지 분석 시간은 제외했다. 한 영상과 인위적인 변환만으로 실제 이동 감지율이나 정확도, 실시간 성능을 일반화할 수 없다. 해당 영상으로 학습하거나 독립 위치 정답을 평가하지 않았다.

실측 평가에는 경기장 길이·폭과 보정에 쓰지 않은 선 교차점의 실제 좌표가 필요하다. 프레임에서 독립 점을 표시하여 거리 오차의 중앙값·95백분위·최대를 구하고 화면 위치별로 나눈다. 선수 발 위치도 별도로 수동 표시한다. 주간·야간, 조명, 가림, 카메라 기종과 거리, 흔들림·줌을 달리한 여러 경기의 영상에서 실제 이동 및 비이동 구간을 사람이 주석하고 이동 감지의 오탐·미탐과 보류율을 측정한다. 경기 단위로 영상을 분리해 임계값 선정 자료와 평가 자료가 섞이지 않도록 한다. 기준 프레임만으로 실제 위치 오차를 알 수 없다.

## 라이선스 및 자료

추가 학습 가중치·데이터셋·외부 소스코드 복사는 없다. 사용한 OpenCV 버전 및 라이선스는 설치 환경의 패키지와 [OpenCV 라이선스](https://github.com/opencv/opencv/blob/4.x/LICENSE)를 확인한다. SoccerNet과 PnLCalib 저장소는 연구 참고 자료이며, 코드·가중치·데이터를 도입하기 전 각각의 원본 라이선스와 데이터 이용 조건을 따로 확인해야 한다. 실험에 사용한 기존 영상의 배포·학습 권한은 확인하지 못해 재배포하거나 학습에 사용하지 않았다.
# 별도 고정 배경 영역을 이용한 카메라 움직임 검사

경계에서 좌표 계산 시 부동소수점 반올림으로 인한 잘못된 보류를 줄였다. 이미지 다각형에서 0.01픽셀 이내이면서 경기장 경계에서 1mm 이내인 경우만 경계로 정정하며, 그 밖의 외삽은 계속 보류한다. AI Hub 검증 정지 이미지 64장에서 선 주석의 교차점 128개를 확인했을 때 보류 64개가 이 조건에서 반환되었다. 추정 오차 중앙값 0.204m, 90백분위 0.462m였으나 105×68m 가정과 같은 골라인 주석 공유가 있으므로 독립 실측 정확도가 아니다. 선수 위치나 전체 화면의 적용 범위가 확대됐다는 뜻도 아니다.

선택 설정 `calibration.camera_guard_feature_region`에 기준 영상의 픽셀 좌표로 볼록 사각형 네 점을 순서대로 입력하면, ORB 카메라 가드는 경기장 보정 사각형 대신 이 영역의 특징점을 사용한다. `camera_guard_reference`와 실제 `image_size_px`가 필요하다. 움직이지 않는 울타리나 경기장 구조물 등에서 사용자가 직접 선택한다. 선수나 화면의 움직이는 부분, 광고판 등에서 선택하면 오판할 수 있다. 기본값은 기존과 동일하게 보정 사각형이다. **이 영역은 움직임 판별용이며 선수의 투영 허용 영역을 넓히지 않는다.** 화면 내 정적인 물체를 확인할 수 없으면 사용하지 않는다.

SoccerNet GSR SNGS-033 중계 영상 50프레임에서는 기존 보정 사각형을 썼을 때 모두 특징점이 부족했고, 전체 화면을 진단용으로 지정하면 안정 2·이동 47·판단 불가 1이었다. 실제 고정 ISSIA 50프레임에서 전체 화면 진단 결과 50개가 안정이었다. 전자는 움직이는 선수 등도 포함한 실험으로 현장에 전체 화면을 권장하는 뜻이 아니며, 움직임의 독립 정답이 없고 하나씩의 영상이어서 정확도를 보장하지 않는다. 화면이 안정으로 판정돼도 렌즈 왜곡, 카메라 움직임, 동적 배경이나 보정점 오차를 놓칠 수 있다. 별도 검증점과 고정 카메라가 계속 필요하다.
