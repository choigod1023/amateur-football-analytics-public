# 역할 모델 교체가 실제 추적·미니맵에 미치는 영향

2026-11-15. 89.10%→91.28% 역할 분류 결과를 선수 신원이나 미니맵 개선으로 확대하지 않고, 같은 야간 녹화 60초를 두 모델로 실제 실행했다.

## 고정 조건

`work/live-dashboard-validation-20261113/replay-1950-2010.mp4`의 300개 분석 프레임(5fps), 같은 YOLO11n 타일 탐지·BYTETracker·IdentityGuard·미니맵 보정·발점 필터를 사용했다. 모델만 `role-final/clean_baseline.pt`와 `clean_candidate.pt`로 바꿨다. 각 모델을 전체 영상에서 별도로 실행했다.

동시에 개발 중인 PositionGuard 수정과 효과가 섞이지 않도록 직전 고정 작업트리 `football-own-match-benchmark-1115`의 실행기를 사용하고 코드 SHA256이 두 실행 사이 바뀌지 않았는지 확인했다. 따라서 이 결과는 새 PositionGuard와 모델을 함께 적용한 결과가 아니다. 출력·영상 snapshot은 신규 `work/minimap-tracking-validation-20261115/role/`에만 기록했다. 서버와 원본 답은 바꾸지 않았다.

**raw 추적 상자·ID 배열과 IdentityGuard 이후 관측 상자·ID 배열이 300프레임 모두 완전히 같았다.** 이 실행 경로에서 분류 모델은 팀 판단을 바꾸지만 추적기 자체의 ID 연결은 바꾸지 않는다.

팀 변경·과다 인원·맵 소실 지표는 줄었지만 표시 관측도 81건 줄었다. 덜 표시해서 얻은 안정성도 있을 수 있어 누락 복구 성공으로 단정할 수 없다. `None` 팀은 관중·심판 제외와 초기 미확정을 모두 포함하므로 전부 미분류 선수라고 부르지 않는다. 팀 변경은 동일한 임시 ID의 색상 변화이며 실제 신원이 바뀐 횟수와 다르다.

## 기존 사람 답 8개로 확인한 재등장

기존 d0108~d0115 답의 ID·source=human·fingerprint·영상 SHA256을 확인했다. 해당 앞뒤 시각에 사람 검토 상자와 현재 관측 상자를 IoU≥0.5, 차선 후보와 차이≥0.1로 연결했으며 모든 8개 장면이 대응됐다. 과거 raw ID를 임의로 새 실행에 이식하지 않았다.

- 사람이 같은 선수라고 확인한 7개 쌍: 두 모델 모두 서로 다른 임시 ID로 남았다.
- 사람이 다른 선수라고 확인한 1개 쌍: 두 모델 모두 분리 상태를 유지했다.

이 결과는 **분류 모델 교체만으로 이미 확인한 7개 재연결이 고쳐지지 않음**을 보여준다. 재연결 옵션을 끈 채 모델 효과만 비교한 것이며, 수동 연결 기능을 포함한 모든 시스템이 실패한다는 뜻은 아니다. 또한 이 답은 과거 학습·개발에 사용돼 새로운 독립 평가가 아니다.

## 코칭과 미니맵 정확도의 한계

- 기본 모델: 7초 box_attack, 20초 gap_wide.
- 후보 모델: 15초 line_drop, 23초 gap_wide, 35초 box_attack.

알림이 2개에서 3개로 바뀌었지만 해당 전후 영상에 대한 사람 정답은 없다. 따라서 코칭 정확도가 높아졌다고 주장하지 않는다. 두 조건 모두 전체 선수 신원 정답과 실측 발점 정답이 없어 `identity_accuracy`, `position_error_m`은 null이다. 속도 상한 통과는 경기장 위치가 맞다는 증명이 아니다.
