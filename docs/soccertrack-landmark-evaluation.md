# 현재 고정 광각 영상의 제공 기준점 검증

현재 로컬 재생목록의 SoccerTrack v1 `20200220` 영상(6500×1000)과 이름이 일치하는 경기의 공식 GPS CSV 네 개를 공개 원본에서 로컬로 받았다. 별도로 원 제작자가 공개한 `fisheye_keypoints.json`과 `gnss_keypoints.json` 각각 65개를 확인했다. [데이터셋 소개](https://github.com/keisuke198619/SoccerTrack), [공개 파일 목록과 라이선스 표기](https://www.kaggle.com/datasets/atomscott/soccertrack). Kaggle 메타데이터는 LGPL 3.0이라고 표기한다. 데이터의 별도 사용 조건을 최종 확인하지 못했으므로 원본·좌표를 저장소나 공개 서버에 넣지 않는다. 기준점은 저자가 제공한 수동 표시이며 자동 검출 결과가 아니다.

제공 좌표의 경기장 중앙점 `(52.5, 34)`은 화면 중앙선에 놓였고 모서리들도 현재 6500×1000 영상의 경기장 모서리와 육안으로 부합했다. 다만 이 정합 확인이 전체 지점의 원본 측정 정확성을 보증하지는 않는다. 제공된 105×68m는 **이 데이터의 좌표계**이며 다른 경기장의 실제 크기를 뜻하지 않는다. 원본 화면은 저자의 광각 보정 처리를 거친 영상으로, 직선 호모그래피가 일반적인 아이폰의 렌즈 왜곡에 그대로 유효하다는 근거가 아니다.

65점 중 바깥 네 코너만 사용해 평면 변환을 구하고 나머지 61점을 피팅에 쓰지 않고 대조했다. 제한 없는 변환에서는 중앙 0.481m, p90 1.287m, 최대 3.182m였다. 실제 서버와 같은 영역·경계 검사를 적용하면 61점 중 20점만 좌표가 반환됐고 중앙 0.686m, p90 1.260m, 최대 1.808m였다. 나머지 41점은 반환되지 않았으며 양 끝 및 경계점이 많아 영상에서 보이는 모든 선을 사용할 수 있다는 뜻이 아니다. 별도 이미지나 경기에서 직접 실측한 값이 아니라 한 이미지의 저자 표시점을 나눈 결과다.

원본 CSV의 사람 박스에서 바닥 중심을 임의로 발 위치로 근사해 4개 영상에서 1초 간격으로 뽑은 2,639개 관측 중 2,556개가 안전 사각형 검사와 경기장 범위를 통과했다. 사람의 실측 위치와 비교한 정확도가 아니다. `project` 함수 호출만 평균 약 0.010ms였으며 탐지·GPU·입력 지연을 포함하지 않는다. 각 영상 2, 10, 20, 25초의 16프레임을 배경 영역을 지정한 ORB 가드로 비교한 결과 전부 `stable`, 평균 6.7ms였다. 한 카메라의 상관된 샘플이고 영역에 나무가 있어 움직임 검출을 보증하지 않는다.

GNSS CSV는 영상의 25fps 프레임과 다른 10Hz 시각을 사용하고 선수 번호 형식도 다르다. 공식 자료는 GNSS로 반자동 주석을 생성했다고 설명하므로 두 자료가 완전히 독립인 정답도 아니다. 번호를 단순 대조하면 오차가 컸다. 전반 12개 초 단위 프레임에서 가능한 -2~+2초 지연과 1:1 대응을 거리 최소화로 선택한 뒤 후반 13프레임에서 고정 평가한 예비 시험도 286관측 중앙 16.02m, p90 33.72m였다. 동기화·실제 ID 대응이 확인되지 않아 이 수치를 모델의 실제 위치 오차라고 해석하거나 선수 정보를 주입하지 않는다.

후보 설정 생성 및 수동 표시점 보류 평가는 다음과 같다. `--output`은 존재하지 않는 로컬 파일만 생성하며 `validated:false`로 고정된다. 제공 기준점을 이미지에서 자동으로 찾는 기능이 아니다.

```powershell
.venv\Scripts\python.exe scripts\experimental_panorama_groundtruth.py <fisheye_keypoints.json> --base <기존_설정.json> --output <새_후보_설정.json>
```

## 녹색 영역과 선 자동 검출 예비 실험

현재 4개 광각 영상의 2·10·20초 총 12프레임을 사용했다. 이미지 녹색 마스크, 밝은 선 후보와 Hough 직선으로 네 모서리를 자동 추정하고 **사후에만** 원저자 표시점과 비교했다. 네 모서리의 픽셀 오차 중앙값은 순서대로 208·420·75·70px였으며, 나머지 61개 표시점에 대한 프레임별 중앙 미터 오차의 중앙값은 20.64m였다. 12프레임은 모두 같은 카메라다. 경기장 밖 펜스·광고선이 선택되고 광각 선의 곡률과 가림이 오차 원인일 수 있다.

먼 잔디 경계보다 아래에 있고 한쪽 옆으로 녹색 픽셀이 75% 이상 연속된 선만 사용하자 유효 후보는 12개 중 10개가 됐고, 모서리별 픽셀 중앙오차는 196·370·70·70px, 프레임별 중앙 미터 오차의 중앙값은 19.57m였다. 미터 오차는 사각형 외삽도 포함한 연구 점수이며 실제 위치 반환 여부와 다르다. 색·길이 임계값과 보조 규칙을 이 영상에서 반복 선택했고 독립 경기나 야간을 시험하지 않았다. 개선 폭이 미미하고 실용 오차가 커서 어떤 자동 보정도 승인하거나 운영 서버에 적용하지 않았다. `scripts/experimental_green_pitch.py`는 영상 경로와 저자 기준점 경로를 받아 두 후보의 평가 결과만 출력한다.

후속 과제는 원본 촬영 시점/ID 대응을 제공자가 명시한 자료로 검증하고, 보정에 쓰이지 않은 실제 선수 발 위치를 평가하는 것이다. 여러 다른 경기·촬영 위치에서 선 검출과 경기장 실측 치수를 검증하기 전에는 이 영상 전용 제공 기준점을 일반 자동 보정으로 취급하지 않는다.
