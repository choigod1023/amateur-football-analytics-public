# 미니맵의 약한 탐지 보충 검증

## 적용 범위

`scripts/run_live_feedback.py --recover-low-confidence`는 검출기 입력 임계값을 기존 0.10에서 추적기의 하한 0.06까지 낮춘다. **ByteTrack에는 원래 임계값을 넘는 상자만 전달한다.** 낮은 점수 상자를 추적기에 직접 넣는 실험은 ID 대응이 달라져 운영 적용에서 제외했다.

미니맵 보충은 직전 분석 프레임(최대 0.25초)에 팀과 위치가 표시된 선수만 대상으로 한다. 현재 영상에 실제 약한 탐지 상자가 있어야 하며 IoU 0.6 이상, 다른 후보 IoU 0.1 이하, 상자 높이 비율 0.8~1.25, 발 위치 이동 0.2높이 이하를 요구한다. 현재 추적 ID가 이미 있거나 강한 탐지와 경쟁하면 제외한다. 경기장 밖, 12m/s 초과 이동, 다른 표시점과 0.75m 미만, 팀 11명 초과도 제외한다.

보충점은 다음 보충의 기준이 되지 않는다. 관측 없이 화면 밖 선수를 만들어 두지 않는다. 원래 추적기, 외형 모델, 팀 투표, 위치 필터, 코칭 입력을 수정하지 않는다. 보충점에는 `observation_kind=low_confidence_recovery`를 붙이고 API에 `recovered_player_ids`를 추가한다. 화면에 보충 수와 코칭 계산 제외를 표시한다. 기존 필드는 유지한다.

## 실제 영상 전후 결과

동일 녹화 1950~2010초, 5fps, 300프레임, 기존 모델·수동 cam3 보정(89×60m 추정)을 사용했다. 정답을 새로 끼워 넣거나 사용자 답을 변경하지 않았다.

| 측정 | 기존 | 최종 후보 |
|---|---:|---:|
| 관측 공백 뒤 같은 ID 재등장 횟수 |245|244|
| 위치 표시 중앙값 |18|18|
| 새로 보충한 점-프레임 |0|6|
| 기존 표시점 변경·삭제 |0|0|
| 표시 속도 12m/s 초과 |0|0|
| 표시 가속도 p95 (m/s²) |15.747|15.784|
| 코칭 알림 |2|2|

공백 지표 개선은 **0.41%로 작다**. 6개의 추가 점이 6개의 공백 전체를 없앤다는 의미가 아니다. source_tracks, players(코칭용 원본), raw_positions, identity_events, alerts는 전체 300프레임에서 정확히 같았다. 따라서 이 구간의 기존 ID 전환·코칭 결과를 바꾸지 않았다. 이는 기존 ID가 정확하다는 증거는 아니다.

단순 0.06 추적기 입력은 공백235회, 제한적 추적기 입력은242회였으나 일부 ID 대응이 바뀌었다. 위치의 마지막 유효 기준만 유지하는 오프라인 실험도246회로 나빠져 제외했다. 최종안은 개선 폭보다 기존 결과 보존을 우선했다.

## 인간 답과 한계

기존 인간 JSON 1,187개 해시를 비교해 변경0개를 확인했다. d0105 `same`는 비교 구간 안에 있지만 부분 상자로 두 번째 IoU가0.216이라 엄격한 IoU0.5 정답 대응을 통과하지 못한다. 다른 두 ID 정답은 이 구간 밖이다. 이 답들은 개발에 이미 사용했으므로 독립 평가가 아니다.

전체 장면의 완전한 사람·개인 ID·경기장 위치 정답은 없다. 추가6개의 실제 장면 확인과 기존 출력 불변 검증을 전체 오탐률·ID 정확도 입증으로 과장하면 안 된다. 선수 완전 가림, 긴 미탐, 다른 선수로 잘못 이어진 기존 ID, 미터 위치 오차는 남아 있다. 코칭 정확도가 좋아졌다는 근거도 없다.
