# 관측 위치 변화 실험

`MovementTracker`는 사용자가 검증한 고정 카메라 보정과 팀 분류, 신뢰할 수 있는 영상 시간축이 모두 주어진 경우만 두 시점의 정규화 좌표를 m로 환산해 관측 변위와 구간 평균 직선 변위 속도를 제공합니다. 이전 시점과 다음 시점에서 같은 임시 ID가 이어지고 중간에 사라지거나 팀이 바뀌지 않아야 합니다. 0.25~2초 구간에서 0.2m 미만 변화나 10m/s 초과 급변은 제외합니다. 이 수치는 검증된 축구 선수 속도 한계가 아닌 보수적인 시험용 필터입니다.

입력 시각은 재생 속도와 독립적인 검증된 미디어 시간이어야 합니다. MP4를 원래 프레임 순서로 빠짐없이 읽는 경우 유효한 FPS와 프레임 인덱스로 계산한 시각을 사용할 수 있습니다. 드롭 프레임 또는 가변 프레임 레이트가 있는 경우 그 계산을 신뢰하지 말고 실제 프레젠테이션 타임스탬프가 필요합니다. SRT/RTSP 디코딩 시각이나 분석 완료 시각은 촬영 시각이 아니므로 신뢰 가능한 영상 시간축을 확인하기 전에는 `timeline_reliable=False`로 두고 결과를 비워야 합니다. 시작·재연결·카메라 이동·보정 변경 시 반드시 reset합니다.

동일 ID 유지 여부는 보장할 수 없으며 짧은 시간 간격에도 ID 바뀜·가림·조명·픽셀 오차·보정 오차가 남습니다. 출력은 구간 내 실제 이동 거리나 전체 선수 이동이 아니고 두 점의 직선 변위입니다. 피드백은 원본 영상 확인을 권하는 관찰만 하며, 전술 판단이나 자동 개인 코칭으로 해석해서는 안 됩니다. 현재 계산은 단위 테스트상의 합성 좌표로만 검증되었고 실제 경기의 속도 정답과 비교하지 않았습니다.
