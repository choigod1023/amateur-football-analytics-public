# 새 사람 답을 반영한 재연결 모델의 다른 경기 검증

2026-11-14. **ID 변경은 조금 줄었으나 오연결이 크게 늘어 후보 모델은 운영에 적용하지 않는다.**

## 비교 조건

기존 4쌍 모델과 새 답을 포함한 9쌍 모델을 같은 `TemporalLinker`에 넣었다. 새로 저장된 d0113~d0115뿐 아니라 같은 시점에 저장된 기존 대기 d0111~d0112도 포함한다는 결정을 평가 전에 고정했다. 학습 자료는 같은 사람 8쌍/다른 사람 1쌍이다. 요청한 세 답만 추가한 7쌍 모델은 학습 진단용이며 이 평가에서 여러 후보를 골라 최고점만 보고하지 않았다.

두 모델에서 특징 구조·0.9 승인 점수·0.15 후보 차이·1.5 신체 높이 운동 잔차·3프레임 확인·2프레임 출력 지연을 동일하게 고정했다. 점수는 동일인 확률이 아니다. 추적 알고리즘을 전역 할당으로 동시에 바꾸지 않았다.

학습에 쓰지 않은 AI Hub 경기 305와 306의 원영상을 실제 GPU로 다시 디코딩·탐지했다. 각 영상 0–30초, 300–330초, 600–630초의 총 90초를 5fps로 평가했다. 합계 180초/900분석 프레임이다. YOLO11n의 전체 프레임 1280 입력·conf 0.1·사람 클래스 탐지를 한 번만 계산하고 같은 BYTETracker 출력을 두 연결기에 공급했다. 정답 ID는 채점에만 사용했다.

두 모델의 학습 경기 그룹을 검사하고, 평가 영상 파일 SHA256이 새 모델의 실제 학습 원본 해시 목록에 없는지 확인했다. 기존 모델에는 원본 해시 목록이 없으므로 기존 모델 자체의 직접 검사는 그룹 기준이다. 새 학습 manifest는 기존 4쌍도 포함하며 그 원본 해시를 기록한다. 결과에는 두 모델·원영상·정답 파일·탐지 가중치·공유 탐지 배열의 SHA256을 남겼다.

## 결과

| 영상 | ID 변경 이전 → 이후 | 승인 연결 이전 → 이후 | 연결 시점 오연결 이전 → 이후 |
|---|---:|---:|---:|
| 305 | 1,641 → 1,636 | 9 → 22 | 1 → 7 |
| 306 | 1,622 → 1,616 | 6 → 18 | 1 → 8 |
| 합계 | **3,263 → 3,252** | **15 → 40** | **2 → 15** |

연결 시점 채점에서 정연결은 8→11, 미확정은 5→14였다. 보다 엄격하게 연결 전 마지막 관측과 확인 구간 전체를 대조한 경계 감사에서는 정연결 **5→6**, 오연결 **2→14**, 미확정 **8→20**이었다. 두 채점 정의를 섞어 쓰지 않는다.

ID 변경 11회(약 0.34%) 감소만 보고 개선이라고 판단하면 잘못된 선수 병합을 놓친다. 새 모델은 연결을 더 많이 승인했지만 그 중 잘못된 연결이 늘었다. 실제 선수 신원을 유지하는 정확도가 좋아졌다는 증거가 아니다. 기존 탐지와 추적을 공유했으므로 GT 매칭 5,878, 미매칭 GT 12,234, 미매칭 탐지 5,287은 두 방식에서 모두 같다. 미매칭 탐지를 모두 오탐이라고 부를 수 없다.

앞뒤 경계 감사에서 후보만 새로 승인한 연결과 기존 연결의 차이는 `changed-joins.json`에 기록했다. 관측 버퍼의 게시 지연은 0~0.4초 범위였으며, 출력 이후의 프레임으로 과거 ID를 수정하지 않았다.

## 해석과 한계

새 답이 대부분 긍정 사례라 작은 학습 집합이 같은 사람 8/다른 사람 1로 구성됐다. 긍정 사례에서 점수가 높아지는 학습 성과가 다른 경기의 구분 성능으로 이어지지 않았다. 부정 사례 부족과 특징의 구별력 한계가 원인 후보지만, 이 두 번의 평가만으로 각각의 기여도를 확정할 수는 없다.

이 경기들은 학습에는 쓰지 않았지만 앞선 실험에서도 이미 평가한 자료다. 완전히 새로운 최종 테스트라고 부르지 않는다. 채점은 기존 greedy IoU≥0.5 기반 진단이며 공식 HOTA/IDF1이 아니다. 5fps 평가이며 최신 아이폰 전체 운영 파이프라인이나 코칭 정답률을 검증한 것은 아니다. 경기장 위치 오차는 이 실험의 대상이 아니다.

후보를 운영에 적용하지 않으며 결과를 본 뒤 임계값을 바꾸어 같은 평가 최고점을 찾지 않았다. 다음 학습에는 학습 경기 안에서 비슷한 유니폼의 다른 선수, 교차·가림 뒤 다른 선수, 운동은 유사하지만 신원이 다른 후보를 검증된 부정 사례로 보강해야 한다. 이번 평가 정답을 학습에 넣는다면 해당 영상은 평가에서 제외하고 별도 경기로 최종 평가해야 한다.
