# 페널티 지역 네 선을 이용한 보정 후보

`python scripts/calibrate_penalty_lines.py input.json`은 사용자가 같은 원본 프레임에서 직접 확인한 골라인, 페널티 지역 앞선, 위·아래 측면선의 두 끝점을 읽어 교차점을 구한다. 실측 경기장 크기와 표준 페널티 지역 규격(깊이 16.5m, 폭 40.32m)을 사용한다. 다음은 **형식만 보여주는 가상 좌표**다.

```json
{"image_size_px":[1920,1080],"field_size_m":[105,68],"side":"left",
 "lines":{"end":[[100,100],[100,700]],"front":[[500,100],[500,700]],
          "top":[[100,100],[500,100]],"bottom":[[100,700],[500,700]]}}
```

`side`는 경기장 x축 기준 왼쪽 골라인이면 left, 오른쪽이면 right다. `top`은 경기장 y가 작은 선, `bottom`은 큰 선이다. 카메라의 시각적 좌우나 원정·홈 팀과 자동으로 일치하지 않으며 사용자가 방향과 선 종류를 확인해야 한다. 선이 화면에서 짧거나 거의 평행해 교차가 불안정한 경우, 교차점이 화면 바깥이거나 선분 끝에서 20px 이상 떨어진 경우는 거절한다. 결과는 항상 `validated: false`다. 실제 독립 검증점과 경기장 치수, 프레임 해상도와 고정 카메라를 확인하기 전에는 활성화하지 않는다. 이 도구는 선 자동 탐지나 카메라 이동 보정이 아니다. 지정된 사각형 바깥 위치는 기존 서버 정책에 따라 보류한다.

AI Hub 승인 검증 자료의 정지 이미지 선 주석에서 네 선의 교차로 후보를 구성하고, 보정에 사용하지 않은 골지역 앞선·측면선의 교차점을 검사했다. 985장, 1,970점의 중앙 오차 0.161m, 90백분위 0.305m였다. 이 수치는 실제 구장 실측 없이 105×68m를 가정하고 한 이미지의 서로 다른 선 주석을 비교한 결과다. 영상 연계, 독립 측량, 선수 발 위치 오차 또는 아이폰 현장 정확도를 검증하지 않는다. 자료 자체와 학습 결과는 이용 조건에 따라 별도 로컬에 보관한다.
