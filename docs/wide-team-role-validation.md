# 현장 유사 광각 영상 팀·역할 검증

사용자가 현장과 비슷하다고 확인한 SoccerTrack 고정 광각 한 경기에서 실험했다. 6500×1000 영상과 CSV 선수 상자를 사용했다. 각각의 첫 10프레임은 색 후보 형성에, 같은 경기 120~150초 구간은 평가에 사용했다. 팀 0/1만 사람이 플레이하는 팀이라는 CSV 해석을 사용했으며 원본 주석의 오류 가능성이 있다. 정답의 각 팀과 임시 색 그룹 번호를 대응시키는 데는 첫 10프레임의 정답을 쓰고 평가 구간 정답은 쓰지 않았다. 자동으로 우리 팀의 이름을 알게 되는 방법이 아니다.

## 정답 상자에서 팀 후보

평가 구간에서 1초 간격으로 30프레임, 팀 지정 선수 660회 관측을 평가했다. 정답 선수 상자와 이상적인 안정 ID를 제공했는데도 현재 기준은 올바른 그룹 225, 반대 그룹 30, 보류 405회다. 동일 인물 반복 관측이고 심판·골키퍼 역할 정확도도 측정하지 않아 실제 자동 추적 정확도나 독립 표본 660개가 아니다. 시작 10프레임을 길게 펼쳐 수집하는 실험도 228/42/390이거나 초기 중심을 만들지 못해 채택하지 않았다.

기존 색상 히스토그램의 단순 K-means(거리 보류 없음)는 정답 457, 오류 169, 보류 34였고 HSV 원형·중앙값 특징은 각각 394/232/34, 267/359/34였다. 첫 10프레임의 정답 팀 라벨로 별도 선형 분류기를 지도학습했을 때도 점수 0.7 이상만 사용하면 331/49/280, 0.9 이상이면 42/0/618이었다. 이 점수는 보정된 확률이 아니고 같은 경기의 정답 팀을 사용했으므로 무감독 운영 해결책이 아니다. 시도한 방법은 운영에 적용하지 않았다.

## 실제 탐지와 후보

기존 YOLO11n 모델을 원본 해상도 타일과 ByteTrack으로 CPU 실행했다. 10프레임으로 그룹을 만들고 나중 구간의 연속 30프레임을 정답 상자와 IoU 0.5 이상 일대일 매칭했다. 정답 상자 660회 중 140회만 탐지 상자와 매칭됐고, 미매칭 탐지는 267회였다. 정답 누락이나 매칭 실패도 가능해 미매칭 탐지를 전부 오탐으로 보지 않는다.

| 색 중심 거리 상한 | 매칭된 140회의 일치 / 오류 / 보류 | 미매칭 탐지 267회 중 그룹 표시 |
| --- | --- | --- |
| 0.2 | 52 / 2 / 86 | 70 |
| 0.3 | 107 / 3 / 30 | 134 |
| 0.4 (현재) | 121 / 3 / 16 | 156 |
| 0.7 | 123 / 3 / 14 | 210 |
| 제한 없음 | 123 / 3 / 14 | 240 |

이 결과는 선택된 140개에 조건부인 낙관적 수치이고 같은 선수의 연속 프레임이다. 특히 미매칭·역할을 판정하지 못하는 문제가 남아 팀을 자동 확정하거나 코칭에 쓸 근거가 아니다. 임계값 0.2는 후보가 줄지만 잔여 오류가 2건이므로 안전한 확정 판정도 아니다.

그룹 번호에 팀 정답을 대응시키지 않고 0.4 후보 그룹의 정답 구성을 사후 집계하면, 정답과 매칭된 후보 124회 중 그룹 0은 팀 0 세 건·팀 1 74건, 그룹 1은 팀 0 47건·팀 1 0건이다. 각 그룹의 다수 팀을 사후에 고르면 121/124지만, 이 비율은 미매칭 탐지 156건을 제외하고 같은 선수·30개 연속 프레임을 반복한다. 화면에는 `home`/`away`나 역할을 자동 확정하지 않고 색상 후보 A/B로만 표시한다.

[Koshkina 등(2021)](https://openaccess.thecvf.com/content/CVPR2021W/CVSports/html/Koshkina_Contrastive_Learning_for_Sports_Video_Unsupervised_Player_Classification_CVPRW_2021_paper.html)은 비지도 대조학습 임베딩을 이용한 팀 분류를 아이스하키 자료에서 평가했다. 이 논문의 수치를 축구 광각 영상이나 심판·골키퍼 판별 정확도로 취급하지 않는다. 이 프로젝트에는 현재 해당 학습 모델이나 가중치를 적용하지 않았다.

동일한 초기 프레임·나중 30프레임에서 이 카메라 첫 30초를 학습한 실험 가중치도 실행했다. 정답 매칭은 기본 140→327회, 정답 미매칭은 520→333회, 미매칭 탐지는 267→104회였다. 현재 색상 거리 기준 0.4에서 일치/오류/보류는 121/3/16→246/13/68로 바뀌었다. 두 모델의 색상 그룹은 각각 앞의 정답 10프레임으로 팀 방향만 따로 선택했다. 광각 한 경기에서 탐지를 개선할 여지는 있지만, 독립 경기 검증이 아니고 기존 다른 경기에서 정확도가 크게 떨어진 가중치이므로 운영 모델을 바꾸지 않았다.

## 역할 모델 전이

별도의 AI Hub 역할 모델 두 개에 광각 영상의 팀 소속 상자를 주입해 시험했다. CSV에는 GK의 개별 역할 정답이 없어 역할별 정확도는 계산할 수 없다. 너무 작아 제외된 상자를 뺀 628회 중 연구 모델 1은 필드 412·GK 216, 연구 모델 2는 필드 283·GK 344·심판 1로 예측했다. 광각에 그대로 적용해 안전하다는 근거가 없다. 판정에 팀 라벨을 입력하거나 자동 코칭을 허용하지 않았다.

승인된 자료가 로컬에 있을 때 다음을 각 실행할 수 있다. 연구용 원본·라벨·가중치 이용 조건은 별도 확인하며 외부 배포하지 않는다.

```powershell
python scripts/evaluate_wide_team_gt.py <동일경기-폴더>
python scripts/research_wide_team_features.py <동일경기-폴더>
python scripts/evaluate_wide_team_detected.py <동일경기-폴더> <YOLO-가중치> --test-frames 30
python scripts/evaluate_wide_role_transfer.py <동일경기-폴더> <역할-모델-파이썬> <가중치1> <가중치2>
```

다음은 경기별·카메라별로 분리된 여러 고정 광각 영상에서 사람 탐지 정답 누락을 먼저 점검하고, 팀·심판·GK 정답과 미확인/오분류를 함께 측정하는 것이다. 사용자 실촬영은 최종 현장 일반화 측정에 필요하지만 그 전까지 기존 자료에서 연구를 계속할 수 있다.
